# 回声 Echo

每日一局音频解谜：你的每次操作被实时声化，整局自动谱成一段极具辨识度的 3 秒乐句——利落解题者奏优雅上行，手忙脚乱者奏刺耳乱窜。零剧透、无限可比，天生适合甩进群里播放。

**核心体验与情绪钩子**
把"解谜过程"直接变成"作曲结果"：你不是在听音乐，而是在无意间创造它。钩子是无法伪装的反差——高手的操作天然好听、菜鸟的天然滑稽，短片一放出来，群里不是笑就是惊。

**详细玩法与规则**
每日固定种子一局，含三小关：①滑旋钮逼近隐藏目标音（越近越谐和）②声音版 Simon 复现渐长音序 ③精准落点砸中飘动的目标音符。每次滑动、尝试、擦肩都触发一个音，音高由与目标的距离决定，节奏由你的操作时刻决定。总用时与失误数决定评级，整局操作轨迹即是那句乐句。

**分享卡设计**
结算自动渲染一段 3 秒竖屏音画短片——随声起舞的频谱花（花瓣数=关卡、颜色=评级、旋转随节拍脉动），底部一行"今日 Echo · 你的乐句"加当日编号。只暴露你的旋律、不暴露答案，可直接甩进群播放或发短视频。

**留存与回访**
每日限量同题制造"全网今天都在弹同一首"的谈资；"我的乐句墙"收藏历次短片，连续打卡解锁新音色（钢琴→八音盒→合成器）。周榜按"最悦耳乐句"由算法评分加用户点赞双评产生。

**技术实现（含 AI 调用成本与延迟）**
纯前端 Web Audio API 合成：操作轨迹→量化到音阶→加包络与和声约束保证悦耳，无需实时 AI，延迟 <10ms。短片导出用 Canvas + WebAudio 离线渲染、MediaRecorder 录制，服务端 ffmpeg 兜底。可选 AI 仅用于给乐句起名，离线批量跑，每次 <$0.0005，成本可忽略。

**防滥用/反作弊/内容安全**
种子每日统一，防提前刷题；轨迹上传带时间戳，异常成绩（零失误+超人反应）打影子标记不进公榜。内容安全风险极低——纯合成音、无 UGC 文本或图像，仅需昵称敏感词过滤。

**冷启动与宣发**
主攻短视频平台：音画短片本身就是完美的观赏性素材，找音乐类、解谜类达人打"看我弹出什么鬼东西"。埋一个反向梗"挑战最难听乐句"——比拼谁更炸裂往往比比谁好听更容易传播。

**盈利模式**
Web 端 AdSense（结算页展示广告）+ 导出高清无水印短片的一次性小额解锁；主战场做微信/抖音小游戏版吃 IAA 激励视频（重试、解锁音色看广告，分成 50%）。名气沉淀后卖"音色包"或授权做品牌定制关卡。

**MVP 范围与开发量**
一名前端 1–2 周可出：三关中先做"滑旋钮逼近目标音"一关 + 频谱花短片导出 + 每日种子 + 分享闭环，音色 1 套、榜单后置。核心难点是"轨迹映射到悦耳旋律"的调音，约占一半工时。

**主要风险与化解**
风险一，映射调不好则高手也难听、钩子失效——用音阶量化+和声约束+大量试听兜底。风险二，移动端浏览器音频自动播放限制——首次交互激活 AudioContext、短片内嵌音轨。风险三，玩法一次性——靠每日同题与音色解锁延长生命周期。
