# 心电图 Flatline

每日一道"稳住"挑战：在层层加压的节拍里保持冷静，后台默默记录你每一拍的微反应，最后渲染成一条以假乱真的生命体征条——稳的人得一条近水平的"🫀 RESTING"直线，崩的人得锯齿暴走的"⚠ CODE BLUE·第 7 拍"尖峰。定位：把"心理稳定度"变成一张人人想晒、却看不出题目的心电图。这是全清单里唯一没搜到任何直接对手的纯空白点子，分享卡本身就是最强病毒素材。

**核心体验与情绪钩子**
钩子是自我暴露式的反差幽默：你以为自己很稳，系统当着全网的面把你第 7 拍的手抖画成一记暴走尖峰。心电图是一个绝妙的隐喻载体——它把抽象的"沉住气"翻译成一张有生死感、有医疗仪式感的图。情绪双向：稳住的人炫"我 RESTING 全程平"，崩的人自嘲"我 CODE BLUE 了"，两种结果都想晒。它精准踩中当代人对"情绪失控/专注力崩坏"的集体焦虑，把弱点变成可炫耀的梗。

**详细玩法与规则**
一局约 40-60 秒，14 拍。核心指令简单："跟着节拍，该点时点、不该点时忍住、被要求时按住准星别放。"压力分三段递进：① 假动作段——屏幕给出诱导性闪烁/假提示，考验你忍住不点（抢跳=失误）；② 干扰段——画面开始晃动、准星漂移，你要按住并微调把它摁在中心；③ 暴增段——干扰源密集出现、节奏加快，考验你守住原节拍不被带乱。**后台逐拍采样三类微反应**：迟疑（该动却延迟>200ms）、过度修正（一次输入幅度远超必要）、慌乱乱点（单拍内多次无效点击）。每拍算一个 0-100 的"镇定分"，全程序列既决定成败，也直接驱动心电图波形——稳拍画平线，崩拍画尖峰。判定边界：连续 3 拍慌乱=直接 CODE BLUE；全程无失误+抖动低=极稀有"平线大师 FLATLINE"。每日同一套题、同一随机种子，全网同题可比。

**分享卡设计**
卡片主体是一条横贯全卡的**心电图波形**，从左到右就是你这局的镇定分时间序列：平稳段画成规律低幅的窦性直线，崩溃拍在对应横坐标炸出一记猩红尖峰，尖峰正上方钉一个戳"⚠ CODE BLUE · 第 7 拍"（或全程稳则显示绿色"🫀 RESTING · 72 BPM"）。顶部一行状态标签+当日期号"Flatline #142"，底部小字仅有你的"镇定指数 63/100"和一个空的分享链接。**为何零剧透**：卡片只暴露"你在第几拍崩了、崩得多惨"，完全不显示题目内容、指令、玩法机制——看的人知道"有个考验冷静的东西、这人没绷住"，但不知道具体要做什么，只能点进来亲自试。**为何想炫**：波形是天生的视觉尤物，一条平线是高冷的胜利勋章，一记暴走尖峰是绝佳的自嘲素材，两端都比一个干巴巴的分数好晒一百倍；而"第几拍崩"给了每个人一句现成的配文钩子。

**留存与回访**
日更同题+全网可比制造"今天你稳住了吗"的打卡话题。留存机制：连胜天数（连续 RESTING 天数断了会心疼）、个人"最长平线纪录"、把你和昨天的自己波形叠放对比。榜单只按"镇定指数"排全球分布（"你比 82% 的人稳"），给争胜理由。推送只发一句"今天的第 7 拍在等你"，不剧透。

**技术实现**
纯前端可跑 MVP：Canvas/SVG 画节拍与波形，`requestAnimationFrame` 驱动，`performance.now()` 记录每次输入时间戳，逐拍算镇定分。心电图卡用 Canvas 离屏渲染导出 PNG（或 SVG 转图）。每日种子=日期哈希，保证全网同题。后端极薄：一个存分数与波形序列的接口（Postgres/KV）+ 榜单聚合，静态站+一个无服务器函数即可。无需登录，localStorage 存连胜，可选邮箱找回。

**防滥用/反作弊/内容安全**
分数由客户端计时，天生可伪造。对策：榜单只做"分布展示"不做高价值奖励，降低作弊动机；把每拍原始输入时间戳一并上报，服务端做合理性校验（人类反应时间下限、输入间隔分布、是否机械等距）过滤明显脚本；波形卡由服务端按上报序列复算生成，防止 PS 伪造"完美平线"再回填。内容安全几乎无风险——无 UGC 文本、无社交，唯一外露是波形图，纯数值可控。

**冷启动与宣发**
主打"没有对手的空白"：这张心电图卡在 X/小红书/抖音天然有观赏性和悬念性（"这是什么？""我也想要一条平线"）。运营发极端样本——一条完美平线 vs 一条全程 CODE BLUE 的爆走图做对比。蹭"专注力/情绪稳定"话题，找 ADHD、考试焦虑、电竞选手社群共鸣。短视频里的实时波形跳动本身就有直播观赏性，适合主播挑战。

**盈利模式**
IAA 最实在：一局结束展示激励视频换"复活重测一次今日题"或"解锁高清心电图卡+更多波形皮肤"。展示广告放在结算页。工具/挑战类可做付费皮肤（波形配色、仪器主题、金色平线特效）走小额内购。体量起来后 AdSense 补充。终极价值在名气——这是极易被媒体报道的"新奇病毒小游戏"，靠首爆导流到后续产品或被收购。

**主要风险与化解**
最大风险是"玩法能不能真的做出压力感"——节拍设计不好会既不难也不好玩，需大量手感打磨，MVP 阶段就要反复调三段加压曲线。第二是新鲜感：每日只有种子变、机制不变会腻，需持续加入新干扰类型/新拍型扩题库。第三是易被抄袭且门槛低——靠先发+"心电图"这一强记忆符号抢占心智，快速迭代波形卡的视觉品牌。第四是作弊污染榜单——用服务端复算+分布展示而非奖励来化解。
