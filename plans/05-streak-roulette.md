# Streak Roulette 连胜轮盘

不是一个游戏，而是一个可以套在任何每日游戏上的元机制层。每天有隐藏小概率出现"诅咒题"：玩了赢+2 连胜、输了直接清零，而你事先并不知道今天是不是诅咒日。于是每天多出一个"玩还是跳"的心理博弈，精准命中损失厌恶。

**核心体验与情绪钩子**
钩子是每日一次的微型俄罗斯轮盘：连胜养到 400 天时，面对一道可能是诅咒题的今日谜题，手指悬在"开始"上的那几秒纠结，就是全部乐趣。情绪来自"我攒了这么久，今天到底赌不赌"。它把任何平淡的每日游戏重新注入风险与心跳，让老玩家有了新的元层目标——不是玩得好，而是活得久。

**详细玩法与规则**
在宿主每日游戏之上加一层状态机。每天流程：①开局前给出"今日风险信号"（三档：⚪平安/🟡疑云/🔴强预警，或纯隐藏），信号由真实诅咒概率映射而来但故意模糊。②玩家决策：玩 or 跳过。跳过=连胜冻结不增不减（保命，但每周跳过次数上限如 2 次，防永久苟着）。③若玩：普通日按宿主规则，赢+1；诅咒日赢+2、输清零。关键数值：诅咒日基础概率约 6%–8%，且随连胜越高概率略升（第 300 天可达 12%），制造"越怕越危险"的张力。预警准确度可调：🔴日里约 60% 真是诅咒题（既有信息量又不确定）。边界：断网当天算"跳过"不清零；诅咒题难度可等于普通题（惩罚全在赌注不在难度），避免"既难又致命"的劝退双杀。

**分享卡设计**
炫的是"活着的天数"与"赌赢的瞬间"。主文案模板：`第 412 天 · 我玩了诅咒题，还活着 🎰🔴→🟩`。用一行图标叙事：🔴(强预警)→🎲(我选择玩)→🟩(赢+2)。若清零则有反向的悲剧梗卡：`我的 388 天连胜，今天归零了 💀`——失败卡的传播力甚至更强（幸灾乐祸+共情）。卡上不泄露当日谜底，只讲赌局故事。

**留存与回访**
这就是一台留存引擎：连胜数字本身是最强回访理由，加上"今日是否诅咒日"的悬念让每天必须来看一眼。里程碑（100/365/1000 天）给专属徽章与更凶的诅咒概率作为"高阶挑战"。跳过次数限制逼玩家不能无限逃避，维持张力。

**技术实现（SDK/框架落地）**
定位为一个可嫁接的机制层，交付形态是轻量 JS SDK + 可选托管后端。集成方式：宿主游戏在关键节点调用三个钩子——`roulette.shouldPromptToday(userId)`（返回风险信号档位）、`roulette.recordResult(userId, win|lose|skip)`（更新连胜状态）、`roulette.getShareCard(userId)`（吐出分享卡数据）。诅咒判定用"每用户每日确定性随机"：`hash(userId + date + serverSalt)` 映射概率，保证同一天同一人结果固定且不可预测、无需实时通信。状态（连胜、跳过额度、历史）存宿主自有存储或我们的 Serverless KV。无需 AI。扩容成本极低：纯计算+少量 KV 读写，可全部跑在边缘函数；SDK 走 CDN。提供 React/纯 JS/小程序三套封装。

**防滥用/反作弊/内容安全**
主要作弊是"看到诅咒结果后反悔/改结果保连胜"：故用服务端确定性判定+当日结果一次性写入锁定，客户端无法回滚。防止改本地时间刷天数：以服务器日期为准。多设备刷跳过额度→按账号而非设备计。本身无 UGC，内容安全依赖宿主游戏，机制层不产内容。需向宿主明确成瘾/赌博观感的合规边界：无真实货币、纯虚拟连胜，避免踩博彩红线。

**冷启动与宣发**
双路径：①作为 SDK 免费开放，靠给独立每日游戏"白嫖一套留存+传播机制"来获取集成方（B 端冷启动即找几个已有每日游戏合作示范）。②自建一个样板宿主游戏演示威力。宣发素材天生自带——"我活了 412 天"的截图与"归零惨案"梗图在社媒极易扩散，见机制⑧建造故事+⑥损失话题。

**盈利模式**
SDK 免费打开生态，变现走：托管后端订阅（宿主按 MAU 付费用我们的状态存储与防作弊）；分享卡生成/品牌定制的增值服务；聚合多游戏的"跨游戏连胜档案"做面向玩家的小额订阅。不靠广告。长期价值是成为"每日游戏的标配机制层"后的平台位与被收购潜力。

**MVP 范围与开发量粗估**
MVP：一个 JS SDK（三钩子+确定性诅咒判定+连胜/跳过状态+分享卡 JSON）+ 一个自家样板宿主接入演示。砍掉多框架封装、跨游戏档案、B 端后台。核心逻辑很轻，约 1.5–2 周一人可做，难点不在代码而在概率/预警数值的手感调优（需 A/B 迭代找到"刺激但不劝退"的甜点）。

**主要风险与化解**
①损失厌恶用力过猛→玩家清零后弃坑：给跳过保命额度、诅咒题难度不加码、清零后送"复活赛"软着陆。②宿主集成意愿低→先自证一个爆款样板再推 SDK。③被视作赌博机制的合规/舆论风险→纯虚拟货币、无付费赌注、显著"仅娱乐"标识。④预警设计失衡（太准则无悬念、太随机则不公平）→把预警准确度做成可调参数并持续调优。
