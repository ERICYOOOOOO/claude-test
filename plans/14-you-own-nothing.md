# 你什么都不拥有 You Own Nothing

一间温馨的公寓插画，你点亮的每一样东西都要按月订阅——台灯、沙发、加热座椅、前门，甚至你养的猫。逛完结算：本月订阅 $2,847，你真正拥有的物品：0 件。这是一件 Neal.fun 式的单页讽刺玩具，用点击本身完成对"万物皆订阅"的控诉。

**核心体验与情绪钩子**
钩子是"荒诞的熟悉感"——每个人都被某个订阅套路过，看着一盏台灯也要 $2.99/月时，先是笑，再是脊背发凉。情绪弧线设计成：温馨（一间可爱的家）→ 荒诞（连猫都要月费）→ 顿悟（结算页 0 件拥有）。它不需要"玩得好"，只需要让人一路点下去，越点越离谱，最后被那句"你真正拥有的物品：0 件"击中。

**详细玩法与规则**
单页公寓插画，所有物件初始灰暗、失效。点击任意物件弹出订阅框：台灯 $2.99/月、沙发 $8/月、加热座椅 $5/月、前门 $12/月（不订就打不开门出场景）、猫 $6/月（不订它会"离家出走"变灰）。订阅后物件亮起、播放微动效（灯亮、座椅冒热气、猫呼噜）。右上角"本月总额"随解锁飙升并抖动。**取消任何订阅，那件东西当场变灰、动效停止、猫消失**，反向教育"你只是租客"。逛全屋后点"结算"进入总账页。

**分享卡设计**
结算卡是唯一传播核心：极简收据风格（等宽字体、纸张纹理），逐行列出你订阅了什么、各多少钱，大字总额 **$2,847/月 = $34,164/年**，末行加粗"你真正拥有的物品：0 件"。附一句随机毒舌点评（如"连温暖都是租来的"）。卡片可一键存图，底部小水印带域名。无剧透压力——数字本身就是梗，别人看了会想自己点一遍算算。

**留存与回访**
这是一次性讽刺玩具，不硬做留存，靠"变体"续命：定期上线新场景（订阅制汽车、订阅制身体器官"心跳 $9.99/月"、订阅制天气）。老用户为看新梗回访。轻量钩子：结算页"晒出你的月账单"参与全站"谁的生活最贵"排行；节点营销（黑五、订阅涨价新闻）追加限定房间。

**技术实现**
纯前端单页，零后端即可上线：HTML + CSS + 少量 JS，插画用 SVG 或分层 PNG，物件状态用 CSS class 切换灰/亮 + transition 动效。总额是前端累加。可选加一个极轻后端只做两件事：统计"全站累计虚拟月费"当社交数字、生成分享卡（用 Canvas 前端画即可，连服务器都省）。整站可挂 CDN 静态托管，成本近乎为零，扛百万流量无压力。

**防滥用/反作弊/内容安全**
没有真实支付、无账号、不采集隐私，风险面极小。要注意：① 明确标注"这是讽刺，不会真的扣费"，避免用户误以为绑卡（首屏一行免责）；② 若做全站账单排行，防刷用简单速率限制即可，数字造假无伤大雅；③ 分享卡不嵌用户可注入的自由文本，避免恶意内容借图传播。

**冷启动与宣发**
天生适合社媒病毒传播。主打一条推文/短视频："我在这个网站给我的猫交了 6 美元月费。"配结算页截图。投放到 Hacker News、Reddit（r/InternetIsBeautiful）、小红书/微博讽刺向账号。蹭热点：每次有大公司宣布"XX 功能改订阅制"就转发本站。KOL 只需玩一遍录屏，内容自带笑点，宣发成本低。

**盈利模式**
一次性爆款，别指望它本身赚钱。现实路径：① 页内挂 AdSense/展示广告，靠爆发期百万级 PV 收一波；② 结算页做"支持作者"打赏/周边（印着"You Own Nothing"的收据 T 恤、贴纸）；③ 真正价值是"名气资产"——用它导流到作者的下一个付费产品或作品集，或作为求职/接单的代表作。切忌硬塞内购破坏讽刺纯度。

**MVP 范围与开发量**
一个场景（客厅）、6–8 个可订阅物件、总额累加、一张结算分享卡，足够验证传播力。纯静态，一人 3–5 天可上线，美术是主要工作量（一张分层插画 + 图标）。变体场景后续按需追加。

**主要风险与化解**
最大风险是"看一眼就走、留存为零"——接受它，定位就是一次性梗，用变体和热点二次激活即可。其次是被当成真实收费引发误会，靠首屏免责与全程无支付入口化解。第三是同类讽刺玩具审美疲劳，靠美术质感和文案毒舌度拉开差距——讽刺类产品，文案就是命。
