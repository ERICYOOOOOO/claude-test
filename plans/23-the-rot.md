# 变质 The Rot

你面对一个 2010 年式的干净信息流，全是朋友的真实动态；往下滑，年份自动递增，真人内容被"猜你喜欢/赞助/为你推荐"一点点淹没，顶部"人类含量%"仪表随之下跌。它是一次可交互的 enshittification 祭文——用你自己滚动的手，重演互联网怎么死的。Neal.fun 式单页讽刺、滚动即叙事。

**核心体验与情绪钩子**
钩子是"用滚动这个动作亲手杀死互联网"。开头你会心一笑——2010 年的信息流干净、真诚、全是熟人近况，唤起怀旧。往下滑，年份数字悄悄爬升，广告、推荐、AI 生成内容像霉斑一样蔓延，顶部"人类含量 98% → 71% → 12%"的仪表持续下跌。情绪是温水煮青蛙式的荒凉：你明知在变坏、想停，但"再滑一下看看能坏到什么程度"的手停不下来，这个"停不下来"本身就是主题的一部分。

**详细玩法与规则**
没有输赢，只有一条被年份标记的无限滚动流。滚动位置映射到时间轴（2010 → 2026），每个年份区间按真实互联网演化投放对应"帖子":早期是朋友的生日、旅行、手写长状态；中期插入"你可能认识的人""赞助内容"；后期被"为你推荐""AI 生成""带货直播切片""相似内容 x20"彻底淹没。顶部人类含量仪表按当前屏内真人内容占比实时计算并下跌。滚到 2026 且人类含量跌破 5%，触发终局：弹出你专属的"信息流死亡证明"，记录你滚了多少年、划过多少条真人动态、在哪一年人类含量首次破 50%。

**分享卡设计**
主打"信息流死亡证明"——仿官方证书排版，黑边讣告风："兹证明 ericgu 的信息流于 2026 年逝世，享年 16。死因：算法喂养过量。生前最后一条真人动态发布于 2019 年。"配一条你专属数据（如"你滑过 1,204 条内容，其中 89% 非人类"）和一枚黑色 RIP 印章。第二种是"人类含量曲线卡"：一条从 98% 俯冲到 4% 的下跌曲线截图，标注关键崩塌年份，极具信息图传播力。

**留存与回访**
本质是一次性体验，不强求高频留存——它的价值在一次性的情绪冲击与分享。轻回访靠：① 内容池随机化，二刷会遇到不同的朋友帖子与广告，值得再滑一次；② 定期更新"最新年份"（明年加 2027 区间，讽刺更新鲜的行业丑闻），给回访理由；③ 死亡证明的个人数据可比较，朋友间会互相晒"谁的信息流死得更惨"。

**技术实现**
纯前端单页，零后端即可上线（契合 Neal.fun 模式）。核心是一个虚拟滚动列表：内容条目是本地 JSON 数据 + 少量模板拼装，按滚动位置计算当前"年份"和"屏内真人占比"驱动顶部仪表。所有"帖子"是预写文案 + 占位头像的组合，不接真实用户数据，无隐私问题。滚动性能靠 windowing（只渲染视口附近条目）。死亡证明用 Canvas 生成分享图。可选轻后端仅用于统计"全站平均死亡年份"做社会化对照。

**防滥用/反作弊/内容安全**
风险很低。所有内容自造，头像用抽象生成或授权素材，绝不盗用真实社媒截图与人物肖像（法律红线）。"朋友动态"文案保持通用、去身份化，不影射真人。若加入 UGC（让用户提交自己怀念的老动态）则需过审 + 敏感词过滤，MVP 阶段不开放 UGC 规避风险。死亡证明里的个人数据仅本地计算，不采集真实社交信息。

**冷启动与宣发**
天生适合社媒病毒传播——主题（死亡互联网理论 / enshittification）本身是科技圈、内容创作者的集体怨念，一键戳中。宣发主打"这个网站让你亲手滑死互联网，结尾给你一张死亡证明"，配一段从干净到腐烂的滚动录屏，极强观赏性与转发欲。投放科技媒体、Hacker News/即刻/小红书吐槽向社群。死亡证明的讣告美学天然是截图素材。绑定时事（每次大厂上线更烂的推荐算法时）蹭话题。

**盈利模式**
一次性爆款类，不指望直接变现，靠名气转化。基础可挂 AdSense（讽刺地：页面本身在骂广告，落地页放广告有元幽默张力，但需克制不破坏体验）。更实在的路径：把它当作个人/工作室的"名片型爆款"，用流量导向下一个产品或付费作品；或做成付费买断的精致版（去广告 + 更多年份 + 自定义死亡证明）。可接受品牌联名（反算法立场的产品）冠名。

**MVP 范围与开发量**
砍到只剩：一条 2010→2026 的滚动流、顶部人类含量仪表、一份终局死亡证明分享图。内容池先写 60–100 条帖子模板覆盖各年份即可。不做 UGC、不做后端统计、不做二刷随机化。纯前端一人 1–2 周可出上线级成品，文案打磨（决定成败）是主要工作量。

**主要风险与化解**
最大风险是"文案不够好笑/不够扎心"——这是纯叙事作品，成败全在文案密度与年份节奏，需反复打磨、找目标人群试滑。其次是一次性、缺乏复玩——接受其定位为病毒式一次性体验，靠分享而非留存获利，用随机化和年份更新延长长尾。第三是被指抄袭 Neal.fun 风格——形式借鉴无妨，靠"死亡互联网"这一独特主题与死亡证明机制做出辨识度。
