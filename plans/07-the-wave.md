# 人浪 The Wave

全网只有一道实时脉冲，任意时刻只在一个人手上。它以约 2 秒一棒的速度在陌生人之间接力，任何一个人漏接，整条人链就当场为全网断掉。这是一个把"在场责任"做到极致的实时在场游戏，核心张力只有一句：别当断链的那个人。

**核心体验与情绪钩子**　此刻，全世界的这道光只在你手上。你有大约 2 秒把它传出去，否则一条已经跑了一千多棒、跨越几十个时区的人链会因你而清零。孤独的责任感、被随机选中的宿命感，加上凌晨你这半球快没人时脉冲却朝你飞来的跨时区张力，构成"我不能是断掉它的那个人"的强情绪。

**详细玩法与规则**　屏幕平时是暗的、只显示"第 1,204 棒"实时跳动和当前在线人数。轮到你时脉冲环亮起并倒计时约 2 秒，点击即传给下一个随机在线陌生人；漏接则全网同时断链，本条浪的总棒数 / 存活时长 / 覆盖时区数被刻进"断链纪念堂"，随后从 0 起一条新浪。

**分享卡设计**　接棒者生成"我接住了第 X 棒，把它从东京传向了圣保罗"的荣誉卡（含编号、在线人数、跨越时区）。断链者则收到一张黑色幽默纪念卡："人链在我手里断了，享年 1204 棒"——把失败也变成可炫耀的传播素材。

**留存与回访**　推送是命脉："脉冲正朝你所在的半球飞来"。个人累计接棒数与徽章、纪念堂里"最长存活浪"历史榜、每天固定的"冲纪录"时段，都给人回来的理由。

**技术实现**　难点不在流量而在并发正确性：任意时刻全网只能有一个持有者，这是一个强一致的全局状态。用 Redis 单 key + Lua 原子脚本（或单一协调进程）做 CAS，保证传递即"上一个持有者释放、下一个原子获得"。连接层用 WebSocket 且可水平扩展多节点，服务端从在线连接池随机抽取下一棒；在线人数即连接计数。广播内容极轻——只有"第 N 棒 / 在线数"这类计数，按每 200ms 聚合推一次即可，带宽成本很低，真正的单点只有那把 Redis key。

**防滥用 / 反作弊**　机器人自动接棒会摧毁"人"的意义：加隐形行为验证、随机化接棒按钮的位置与出现时机、按账号 / IP 限速，并对在线人数做女巫防护（防刷假在场）。

**冷启动与宣发**　人少即死，必须先攒到临界在线数才有张力。首发用"约定同一时刻一起开浪"的活动，联合社群做定点接力直播；跨时区宿命叙事天然适合 Twitter / 小红书的图文传播。

**盈利模式**　互动太短，纯 IAA 不现实，主要靠名气外溢。可做纪念堂付费永久铭牌、品牌冠名单场"世界纪录浪"，以及爆红后导流到下一个付费产品。

**MVP 范围与开发量**　一个 WebSocket 服务 + Redis 单 key + 前端脉冲环动画 + 断链纪念堂页，单人约 2–3 周。工作量集中在并发正确性与断链结算逻辑，而非承载量。

**主要风险与化解**　最大风险是冷启动人数不足导致频繁瞬断——用机器人"托底"填充在线池、并把玩家集中到分时段开浪；一人恶意断链带来的挫败——把断链包装成荣誉与黑色幽默而非惩罚，让"断在第几棒"本身成为谈资。
