# 缝合日 Exquisite Corpse

每天系统开一件待拼作品，拆成若干段全天轮流派给随机玩家；轮到你只见上一段边缘露出的一条窄缝，就盲接一句话。午夜完整拼合体一次性向全网揭晓，因无人见过全貌，通常荒诞爆笑。

**核心体验与情绪钩子**
超现实主义"精致的尸体"游戏数字化——集体盲创的荒诞爆笑。钩子是"我参与了却没见过全貌"的悬念，加上午夜一次性揭晓的集体高潮，以及"我画了今日之兽的第三条腿"这种荒诞而具体的署名归属感。

**详细玩法与规则**
每天 0 点系统随机开一件待拼作品（一只怪/一格四联漫画/一段歌），拆成 4–8 段，全天分时段轮流派发，名额有限先到先得。轮到你只能看到上一段边缘露出的一条窄缝 + 一句提示（"这里要接上半身"），你写一句话，AI 据此生成本段并在缝处像素级衔接。你无法回看已完成段。午夜合成完整体向全网揭晓。

**分享卡设计**
揭晓时生成"今日之兽"竖图/短视频——完整拼合体 + 分段拼缝高亮动画（逐段点亮谁接了哪块）+ 每段作者昵称与那句话。你的专属卡高亮"你的第 3 段"，配文"我贡献了这条腿"，天然带梗、天然可传播。

**留存与回访**
每日新题 + "我的参与史"档案（我接过的怪物合集）；连续参与解锁优先派发权与稀有部位（头、脸更抢手）。历史画廊可浏览往期爆笑成品并点赞，UGC 沉淀为可逛内容拉长会话时长。

**技术实现（含 AI 调用成本与延迟）**
核心是分段图像生成+缝合——用扩散模型的 inpainting/outpainting，固定前一段的边缘区域作为条件续画保证接缝连贯；音乐版用音频续写模型对齐拍点。每段生成约 3–10 秒，成本约 $0.01–0.04（自建 SDXL 更省，API 更快）。全天异步、非实时，延迟不敏感。每日调度用定时任务开局、分派、午夜合成。

**防滥用/反作弊/内容安全**
UGC 提示词是重灾区——先过文本审核 API 拦色情/暴力/仇恨，再对生成图跑图像安全检测，双保险；违规段自动重生成或跳过。每人每天可接段数限流防刷；提示词与作者绑定可追溯。缝合结果人工抽审 + 用户举报下架。

**冷启动与宣发**
种子期由官方每天精选最荒诞成品剪成短视频投放，打"人类协作能创造出多离谱的东西"。社群固定"午夜揭晓"仪式感，像追剧一样定点蹲守；邀请好友一起接同一只兽以增强拉新裂变。

**盈利模式**
主力靠激励视频——"抢稀有部位/插队优先派发/解锁高清导出"看广告（小游戏 IAA 分成 50%）；Web 端画廊页挂 AdSense。周边：把最火的"今日之兽"做成可下单贴纸/T 恤（POD 代发）。AI 成本必须靠广告与每日名额严格对冲，每日总生成量要能算平账。

**MVP 范围与开发量**
先做单一品类"一只怪 4 段横向拼接"，跑通开局→派发→窄缝提示→inpainting 续画→午夜合成→画廊揭晓闭环，1 名全栈 + 1 名会调模型者约 3–4 周。漫画/歌曲品类后置。难点在接缝自然度与调度稳定。

**主要风险与化解**
风险一，接缝生硬、成品不好笑——outpainting 固定边缘 + 统一风格 prompt，靠"荒诞"而非"精美"降低质量门槛。风险二，AI 成本失控——每日名额硬上限、自建模型、缓存复用。风险三，UGC 合规——强制双重审核 + 可追溯 + 人工抽审。风险四，人数不足拼不满一件——凑不齐时用 AI 兜底补位。
