# 全网一国 Hive Nation

全网玩家共治唯一一个持久化国家：你每天提案、投票，AI"史官"把当选国法推演成一整年历史，产出新闻公报、国家指标和危机。它是一台"集体荒诞叙事发生器"——今天投的一条烂法律，明年就长成一个自带节日与神话的社会。精神祖先是 NationStates。

**核心体验与情绪钩子**
钩子是"我们一起养出了一个真会记仇、会进化的国家"。你不是玩一局游戏，而是参与一部连载：昨天全网通过"立鸽子为神王"，今天 AI 新闻里就出现《鸽神诞辰全国放假三日》，你的派系被点名批判或封圣。情绪来自共同作者身份 + 后果可见——每条法律都在持久历史里留痕，越叠越离奇，没人能预测国家半年后长成什么妖怪。

**详细玩法与规则**
每日一个议程周期：白天开放提案（自由填空或从热门模板改写），玩家点赞顶起提案，晚上对票数最高的 3–5 条国法投票，最高票入宪。当选法律交给 AI 史官，以"距上次推演一年"的尺度生成本日国是公报：叙述这条法律落地后的荒诞连锁反应，更新四项指标（幸福 / 经济 / 混乱 / 离奇文化值），并抛出一个需明日立法应对的危机（如"人情经济导致全国欠人情崩盘"）。国家有持久记忆：历代法律、神话、节日、指标曲线永久累积，新推演必须与旧设定自洽。

**分享卡设计**
两种卡。国法卡：羊皮纸风格，盖国玺，"由我提案、全网 6,214 票通过的第 88 号国法：全民午睡入宪"，附史官一句锐评。公报卡（更易传播）：当日新闻头条截图，大字荒诞标题 + 四项指标的涨跌箭头（混乱值 +37 尤其上头），底部点名"本条由 XX 派系推动"。卡角二维码直达今日投票，扫码即成为国民投下一票。

**留存与回访**
强回访源于"错过一天就看不懂剧情"：每日固定开票时间制造打卡点，公报像追连载。派系系统提供长期身份与荣誉（你的派系推动过多少国法、幸福贡献榜）。危机机制强制回来——今天不立法应对，明天指标崩、国家闹笑话。周期性"建国纪念日"重播年度大事记，唤回流失用户。

**技术实现**
前端 Web 单页（提案流 + 投票 + 公报时间线）。后端一个每日定时任务（cron）在开票后触发一次 AI 推演，这是全站唯一的重 AI 调用点——每天仅 1 次、面向全体玩家共享同一份产物，成本被百万玩家摊薄到近乎为零。喂给模型的上下文是"压缩后的国家状态"（当前指标 + 最近若干法律摘要 + 关键神话词条），而非全部历史，用滚动摘要控制 token。产物落库为结构化 JSON（叙事文 + 指标增量 + 危机），Postgres 存法律与历史，Redis 扛投票计数。派系点名靠把当日活跃派系名注入 prompt。

**防滥用/反作弊/内容安全**
投票防刷靠账号 + 设备指纹 + 每人每提案一票，机器人农场用行为风控和限流拦截。提案是自由文本，最大风险是仇恨 / 政治敏感内容——先过敏感词与分类器，再由 AI 史官在推演时"软性净化"（把越界提案改写成荒诞而非攻击性的版本，或让它在国内"未获通过"）。史官 prompt 内置红线：不影射真实国家 / 人物 / 宗教，只产出架空荒诞。玩家举报可下架单条法律并触发史官"废除"叙事。

**冷启动与宣发**
冷启动怕"人少投票没戏剧"：开局由官方预设一部有趣的建国前史（已有几条离奇法律和一个神话），新人一进来就有可读的世界和可站的队。宣发主打"这个由网友共治的国家现在有多离谱"——每日把最荒诞的一条公报做成短视频/截图投喂社媒，天然是二创素材。拉小型社群（如某论坛、某主播粉丝）集体"占领国会"推动一条法律，制造派系战叙事。

**盈利模式**
IAA 为主：投票/看公报间隙插激励视频——"看广告为你的提案 +1 加权票"或"解锁史官对某法律的独家番外"，绑定核心诉求。派系可付费定制徽记、名号、专属节日冠名。中长期靠"名气变现"：这个持续进化的荒诞国家本身是内容 IP，可衍生周边、年鉴、付费开放"平行分国"。AI 成本极低（每日 1 次共享推演）是盈利关键优势。

**MVP 范围与开发量**
砍到只剩：每日提案 + 投票 + 一次 AI 推演公报 + 四项指标 + 一条法律持久列表。不做派系、不做危机链、不做神话词条。核心难点是推演 prompt 的状态压缩与自洽，约 3–4 周一人可出可玩 Demo（含预置建国前史）。派系与危机作为第二迭代加入。

**主要风险与化解**
最大风险是 AI 推演"失忆或前后矛盾"，毁掉持久感——靠结构化状态 + 滚动摘要 + 关键设定固化（神话词条不进摘要而是常驻）缓解。其次是有害提案，靠三层内容安全 + 史官软净化。第三是"投票疲劳/剧情失控无人看得懂"，靠每日一条头条式摘要降低理解门槛，并保留官方"史官微调"权重防止国家彻底崩坏。
