# The Last Sentence 最后一句话

全球唯一一个文本框。你提交一句话，它会覆盖上一个人的那句。被覆盖的句子跌进永久滚动的"墓地"，墓碑上刻着它活了多少毫秒。极简、短暂、易逝，人人都想让自己的句子多活一秒。

**核心体验与情绪钩子**
此刻全世界只有一句话是"活着"的，而它是你写的——直到下一个人把你抹掉。张力来自极端的短暂与唯一：你的句子可能只活了 800 毫秒就成了墓碑，也可能凌晨无人时活了三小时。这是一个关于"占据当下"和"注定被取代"的存在主义小玩具。

**详细玩法与规则**
页面正中显示当前唯一存活句子 + 一个跳动的存活计时器（毫秒级）。任何人可提交新句（限 140 字），提交瞬间：旧句被打上死亡时间戳、算出存活毫秒数、推入下方永久墓地滚动列表；新句上位、计时归零。提交需 10-15s 冷却，防止一人连刷霸屏。墓地按时间倒序无限下拉，每条显示：句子内容、存活时长（如"存活 1,203 ms"）、上位/死亡时间。可加"史上存活最久 Top 100"荣誉榜。边界情况：并发提交按服务器到达顺序串行裁决，只有一句能真正"在位"，其余瞬间即被下一句覆盖（存活可能是 0-50ms，反而成梗）。

**分享卡设计**
墓碑卡：黑底，中央你的句子，下方一行冷冽的"存活 1,203 毫秒 · 全球第 48,201 句 · 已死亡"，配一个熄灭的小蜡烛图标和短链。零剧透因为它只是一句话+一个数字，没有需要保护的谜底；想炫是因为"存活时长"是天然的攀比与自嘲素材——活得久值得晒，活 12ms 也好笑到想晒。另可分享"当前存活句"实时卡，配"截图时它还活着"。

**留存与回访**
回访靠三种情绪：想夺回榜首、想守护自己的句子多活一会、想看现在是谁在位。可订阅"你的句子被覆盖了"通知，制造"刚被人抢了，回去反击"的循环。周期性事件（跨年 0 点、整点）会自发变成刷屏抢位战与接龙，形成自组织的回访高峰，无需运营推动。

**技术实现**
前端静态页 + WebSocket 广播当前句与计时。后端极轻：一个权威写入点（Redis 单键存当前句 + 上位时间戳；提交时原子替换并把旧句 append 到墓地列表/时序库）。墓地用只追加存储（Postgres 或 append-only log），分页游标下拉。全球单一状态、无分房间。无需 AI（但内容审核可接一个轻量模型）。扩容便宜：核心是一次原子写 + 一次广播，热点集中在单键，用 Redis 单实例足以扛高频提交；墓地是冷数据，随便存。成本以带宽和审核为主。

**防滥用/反作弊/内容安全**
这是最大风险点：唯一文本框=全球最显眼的涂鸦墙。措施：提交冷却 + 每 IP/设备限速；接入敏感词/仇恨/引流广告过滤（正则黑名单 + 轻量文本分类模型）；命中即拦截或延迟人工复核，不让违规内容"上位"被全球看到。存活时长机制天然抑制刷屏（刷得越凶每句活得越短）。保留可回溯日志，支持事后下架墓碑（下架后保留"[已移除]"占位，维持毫秒计数的完整性）。

**冷启动与宣发**
天然的传播素材是"极端存活时长"截图：晒"我的句子只活了 9 毫秒"或"我霸榜 2 小时"。冷启动发一条"全世界现在只允许存在一句话，去写下你的"的推文/短视频，配上实时页面直播。选一个整点组织首场"抢位战"造势。观赏性强，适合主播开播刷屏互动。

**盈利模式**
现实判断：极简一次性玩具，直接变现空间小。展示广告需要巨大浏览量才有意义，而它的停留时长短。较现实的做法：墓地页做展示广告吃长尾浏览；或"永久点亮"微打赏（付费给你的墓碑加一朵花/高亮，纯虚荣不改机制）。本质仍是"名气→下一个产品"路径，把它当作低成本引爆器而非现金牛。

**MVP 范围与开发量粗估**
MVP = 单文本框 + 存活计时 + 覆盖逻辑 + 墓地滚动 + 内容过滤 + 分享卡。砍掉排行榜、通知、打赏。一名全栈约 3-5 天：核心原子写与广播 1 天、墓地与分页 1 天、前端与计时动画 1-2 天、内容过滤接入 1 天。

**主要风险与化解**
① 内容安全事故（违禁/引流内容占据全球唯一屏）：过滤 + 冷却 + 人工兜底 + 秒级下架，是上线前必须打磨的第一优先级。② 新鲜感一次性、留存差：靠周期性抢位事件与排行榜续命。③ 单键写入热点：Redis 原子操作足够，真扛不住再加分片计数与队列削峰。
