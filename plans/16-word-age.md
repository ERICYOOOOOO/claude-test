# 词龄 Word Age

一个把"英语单词第一次被写下来的年份"变成可分享冷知识的工具站。定位：全清单里最工具化、最吃 SEO 长尾、最能细水长流变现的一个——每个单词一个独立长尾页，靠搜索引擎源源不断带来免费流量。

**核心体验与情绪钩子**
钩子是"反差与被冒犯的惊喜"：你以为很新潮的词其实古老得离谱，你以为庄重的词当年是骂人的。核心情绪是"我居然不知道"——一种低成本的智力优越感，天生适合截图转发。

**详细玩法与规则**
输入任意英文单词，输出四件事：首次被记录的年份、换算出的"实际年龄"（今年-该年）、一句语义变迁小史、以及一个反差参照物（"nice 首见于 1300 年，比美国建国老 476 岁，当年意思是'愚蠢、无知'"）。参照物库由年份自动匹配：比某历史事件早/晚、比某名人年长、比某常用新词老几倍。再给一句判词："比你想的老得多"或"其实是个新词"。支持随机词、今日词、以及"猜年份"小游戏（给词猜生日，越接近分越高）。

**分享卡设计**
竖版卡片：巨大单词 + 生日年份（做成墓碑/出生证/年轮任一视觉母题）+ 判词一行 + 语义变迁一句 + 反差参照一句。底部固定站点域名与"查你自己的词 →"。卡片可一键存图，也生成该词的独立短链，点进去就是可被收录的长尾页——分享行为本身在给 SEO 喂外链。

**留存与回访**
每日一个"今日词"推送（可订阅邮件/RSS），做成日历式打卡。设"我的词库"收藏夹与"猜年份"连胜榜。做主题合辑页（"其实很年轻的 10 个词""骂人变夸人的词"）反复导流，把一次性访客沉淀成回访者。

**技术实现**
纯静态优先：预先离线抓取/清洗 etymonline 与 Merriam-Webster 的首见年份与释义，落成本地 JSON/SQLite，构建期为每个词生成静态 HTML（Next.js/Astro SSG，几万页也能秒开）。参照物与判词是纯前端规则计算，零后端成本。搜索框走客户端模糊匹配，找不到时再回落到服务端查询并按需生成新页。

**防滥用/反作弊/内容安全**
输入做白名单化：只接受词典命中的真实词，脏话/生造词直接返回"查无此词"，杜绝把工具当成脏话生成器。抓取数据须尊重来源版权——只用事实性年份，释义用自有改写而非整段照搬，页面标注数据出处并保留 robots 友好。猜年份榜按设备与频率限流防刷。

**冷启动与宣发**
先批量生成 2000-5000 个高频/高话题词的长尾页，让 SEO 引擎慢慢收；同时在 Reddit（r/etymology、r/todayilearned）、语言学与英语学习社群手动投喂最反差的 10-20 条"词卡"。找语言类 up 主/博主做"猜词龄"挑战素材。标题模板化（"'nice'一词竟然……"）批量产短视频与 Pinterest 图。

**盈利模式**
主力是 SEO 长尾 + 展示广告：单页价值低，但长尾页成千上万、常青且几乎零维护，靠总量堆浏览（AdSense 约 \$1–3/千次浏览，工具站要奔百万级月 PV 才算养活）。叠加：英语学习联盟营销（词典 App、背单词课、留学备考按 CPA 分成，转化远高于纯展示）、"词源日历"周边与高清词卡付费导出、给出版/教育做数据 API 订阅。变现关键是把免费长尾流量导去高客单价的教育联盟，而非只赚广告。

**主要风险与化解**
风险一，数据版权与抓取合规：只取事实年份、释义自写、标注出处，必要时引入公版词源资料（如公有领域的词源词典）打底。风险二，SEO 见效慢、易被大词典站压制：靠"反差参照+可分享词卡"这一它们没有的差异化角度切长尾，而非硬拼词条权威。风险三，单页流量太薄：用合辑页、猜年份互动、邮件订阅把散点流量攒成社区与复访，避免纯一次性。
