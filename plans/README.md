# 策划案合集 · 26 个网页小游戏 / 工具

每份约 800–1600 汉字的详细策划案，统一覆盖 **10 个方面**：核心体验与情绪钩子 · 详细玩法与规则 · 分享卡设计 · 留存与回访 · 技术实现 · 防滥用/反作弊/内容安全 · 冷启动与宣发 · 盈利模式 · MVP 范围与开发量 · 主要风险与化解。

点子清单与筛选逻辑见上级目录 [`../new-viral-web-game-ideas.md`](../new-viral-web-game-ideas.md)；商业化与宣发通论见前面的对话与研究文档。
