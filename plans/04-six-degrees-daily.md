# Six Degrees Daily 每日六度

每天两个随机维基词条，比谁用最少点击从起点跳到终点。全球同题、当日最短路径排行榜，分享卡把你走过的概念链变成一串可炫耀又不剧透的格子。数据源是维基百科的链接图，玩法即"人肉图搜索"的乐趣。

**核心体验与情绪钩子**
钩子是"顿悟连接"——当你意识到从"香蕉"能经"猴子→太空计划→香蕉"（乱来）跳到"黑洞"时的那种大脑放电感。每一步都是一次赌博式的联想，走通一条精妙短链的成就感，加上"全球有人只用了 3 步，我用了 7 步"的胜负心。零门槛（会点链接就行）+ 益智炫技双重满足。

**详细玩法与规则**
每日全球同一对词条（起点 A→终点 B）。完整循环 2–5 分钟：进入起点词条页（我们渲染的简化维基页，只保留正文内链），每点一个内链算一"跳"，目标是到达 B。规则：只能走词条正文里的蓝链，不能用搜索/URL 直达；实时显示已用步数与当前词条。到达即结算，展示你的路径、步数、耗时、全球百分位。关键数值：官方保证 A→B 存在≤4 跳的解（用预计算 BFS 校验，避免地狱题）；日榜按"步数优先、耗时次之"排序。边界情况：走进死胡同页（无出边）给"回退一步"；断网续玩用本地缓存路径。每日一次计入排行，可"练习模式"重玩历史题不计分。

**分享卡设计**
仿 Wordle 格子但显示概念链：`🟩香蕉 → ⬜灵长类 → ⬜航天 → 🟨黑洞  4跳`。用颜色标注步数区间（绿=接近最优、黄=普通、红=绕远），链条本身就是谈资又天然剧透可控——可选"隐藏中间词只留步数与首尾"的无剧透版：`起→⬜⬜⬜→终 4跳 击败89%`。底部固定 `#每日六度 Day127`。

**留存与回访**
每日一题+连胜（连续参与天数）；日榜/好友榜制造攀比；"最优解回放"次日公布，看全球最妙的 3 步解法激发"我下次也要秀"；成就系统（首次 3 步内、连续一周、发现冷门捷径词）。周赛用一对超难词条聚合话题。

**技术实现**
核心是维基链接图。前后端：预先下载维基百科 dump（页面+内链），建反向/正向邻接表存入图数据库或压缩邻接文件；每日选题时跑 BFS 校验可解性与最短步数、生成排行基准。玩法可纯前端渲染简化词条（我们托管精简 HTML，去广告去噪），无需实时（排行榜是异步写入+缓存榜单）。AI 不必需；可选用 embedding 挑"看似无关实则可达"的有趣词对。扩容成本：图数据静态、只读，CDN + 边缘 KV 即可扛大流量，主要成本在一次性 dump 处理与存储。

**防滥用/反作弊/内容安全**
反作弊重点是脚本自动求解与直改 URL：服务端校验路径每一跳的合法性（相邻词条间确有内链、来自当日快照）、限制单跳最短时间过滤机器人、当日成绩需完整路径回放通过才上榜。内容安全：维基本身较干净，但需过滤敏感/成人词条不作为起终点（维护黑名单）；用固定日期快照避免维基被恶意编辑影响题目。

**冷启动与宣发**
这类"维基跳转"玩法本身有历史群众基础（Wikiracing/Wikipedia Game），受众现成。宣发主打分享卡的智力炫耀属性，在 Reddit r/wikipedia、小红书益智圈、X 投放每日题；找知识类 UP 主直播闯关（观赏性强，见机制③）。每日同题让"你今天几跳"成为群聊话题。

**盈利模式**
工具/益智类吃 SEO 长尾好——每对词条的"最优解"页面可被搜索收录导流。变现以 AdSense 展示广告为主（需大流量），叠加"高级练习包/无限历史题/去广告"一次性或订阅小额付费。爆款后走"名气→出版益智书/被知识平台收购"路径。不依赖 IAA。

**MVP 范围与开发量粗估**
MVP：单日一对词条+简化词条渲染+步数统计+分享卡+全球最短基准。砍掉好友榜、成就、练习库。最重的是维基图处理管线（dump 下载/清洗/BFS），约 3–4 周一人可做，其中图数据工程占一半。先用一小语种或英文维基子集验证。

**主要风险与化解**
①维基图数据量大、处理复杂→用现成 Wikipedia dump 与开源链接图工具，先做子集。②题目太难/无解→BFS 预校验保证≤4 跳且非孤岛。③脚本刷榜→路径服务端校验+时间下限+回放审计。④与老 Wikiracing 玩法同质→靠"全球同题+无剧透概念链分享卡+日榜"这套 Wordle 化机制做出差异。
