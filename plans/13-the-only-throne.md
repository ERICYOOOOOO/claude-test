# 王座 The Only Throne

全网只有一把王座，一次只坐得下一个人。现任国王的名字和在位计时器实时滚动，每秒累积荣耀分；越传奇的王，越多人涌来终结他。它是一台把"守擂—掀桌"戏剧性拉满的实时直播机器。

**核心体验与情绪钩子**
钩子是"唯一性 + 公开倒计时"。全网同一时刻只有一个王，屏幕正中一个不断跳动的秒表和一串荣耀分，把"他已经在位 4 小时 22 分"变成一种可被围观、可被嫉妒、可被推翻的公共事件。情绪是双向的：坐上去的人怕被掀，掀不掉的人越挫越勇。悬念随在位时长指数级增长——王越传奇，终结他的诱惑越大。

**详细玩法与规则**
所有人进入同一个"大厅"，只有一人在王座上。系统每约 30 秒发起一次"政变回合"：向大厅里全体挑战者（不含现任王）同时抛出一道 3–5 秒的极短小关，随机取自手速（在正确时刻点击）、技巧（拦截移动目标）、运气（多选一猜中）三类。本回合唯一最快且正确者立即冲上王座，掀下现任。关键设计：**在位的王不能主动防守**，只能眼睁睁看倒计时逼近下一次政变——把张力从"操作"转移到"能撑几轮"。被掀下者的在位时长立刻冻结，连同名字刻入"历代君王殿"排行榜。

**分享卡设计**
两种卡。加冕卡：黑金配色，居中王冠 + "我统治了全网 X 分 Y 秒"，附一句系统生成的谥号（如"三分钟暴君""午夜孤王"）。退位卡（更易传播）：定格被掀瞬间的截图，大字"我的王朝终结于第 N 位挑战者之手"，底部小字显示终结者昵称——制造点名与复仇。卡片右下角二维码直达大厅，扫码即空降当前政变回合。

**留存与回访**
三层钩子：① 历代君王殿长期榜，鼓励刷新最长在位纪录；② 每日 20:00 开一场"限时铁王座"，王座荣耀分翻倍、观战人数最多，制造固定回访点；③ 关注机制——你终结过的王上线时推送提醒，你被谁掀下也可"挂榜复仇"。主播守王座时可开专属房间号，观众空降助攻或截胡。

**技术实现**
前端 Web（React/Canvas），后端用 WebSocket 长连接维持大厅状态。核心是一个权威服务器：政变回合的题目、开始时间戳、判定全部在服务端产生和结算，客户端只上报"我的点击相对回合开始的毫秒差"。用 Redis 存王座当前态和大厅在线集合，回合结算是一次内存排序。荣耀分靠服务端定时累加，不信任客户端时钟。历代榜落 Postgres。单机可撑数千并发大厅观众。

**防滥用/反作弊/内容安全**
手速判定的红线是"服务端计时 + 反应时间下限"：小于人类极限（约 120ms）的响应直接判为脚本作弊，加隐藏随机延迟防止预判。同一 IP/设备指纹的并发上号限流，防脚本农场刷政变。昵称过敏感词过滤 + 举报即时下榜（历代殿里的违规名替换为"某位无名之王"）。回合题目服务端随机，客户端无法预读答案。

**冷启动与宣发**
先解决"没人就没戏剧"：初期用机器人填充大厅制造政变节奏，真人一进来就能立刻打。宣发主打直播——邀请中小主播"挑战守王座 1 小时"，天然产出高能剪辑（被 0.1 秒截胡、连守 20 轮）。短视频侧输出"史上最长王朝被终结瞬间"合集。首页常驻"当前国王已在位 XX"的实时数字，本身就是社交货币。

**盈利模式**
IAA 为主：政变回合间隙插激励视频——"看广告获得一次本回合抢先 0.3 秒的加速权"，直接绑定核心诉求，转化高。付费皮肤（王冠、王座外观、专属谥号）走微交易。中长期可做"付费复活/连击护盾"等不破坏公平的观赏性道具。适合上抖音/微信小游戏走 IAA 分成，比纯 Web AdSense 实在。

**MVP 范围与开发量**
砍到只剩：一个大厅、一种小关（纯手速点击）、王座态、在位计时、历代榜前 20。不做皮肤、不做关注、不做每日赛。核心难点是权威服务器 + WebSocket 同步回合，约 2–3 周一人可出可玩 Demo，机器人填充另需 2–3 天。

**主要风险与化解**
最大风险是"冷启动无人 = 无戏剧"，靠机器人兜底节奏 + 直播定向引流破解。其次是作弊毁掉公平性，靠服务端权威判定 + 反应下限 + 设备限流层层设防。第三是单一小关玩腻，留在迭代池：手速稳定后再滚动加入技巧类、运气类，保持每回合新鲜。
