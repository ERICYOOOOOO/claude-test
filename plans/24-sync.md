# 同频 Sync

每天一道故意开放、没有标准答案的提示（"一个像星期天的颜色""说一个别人都不会说、但你搭档也会说的词"），你被随机匿名配一名全球陌生人盲答，只有两人落在同一答案才计分。它是 Two Truths 的镜像——不是斗智欺骗，而是纯协作收敛，靠想象"一个普通人会怎么想"（Schelling 焦点）与素未谋面的人心灵同频。

**核心体验与情绪钩子**
钩子是"和一个完全不认识的陌生人，脑子里同时冒出同一个词"的战栗。你唯一的武器不是知识，而是共情与直觉：猜想"人类的默认答案是什么""这个特定陌生人此刻会怎么想"。命中时的情绪极强——一种跨越匿名的确认感，仿佛证明了人与人本可同频。错过也上头："我说蓝色你说金色，差一点。"这种"差一点的遗憾 + 命中的电流"是核心复玩驱动力。

**详细玩法与规则**
每日一题，全球同题，提示刻意开放无标准答案（颜色/词/数字/概念联想）。你被随机匿名配对一名当前在线或异步的陌生人，双方互不可见地盲答（限时 + 限字）。系统归一化后比对：完全同频（同一答案）满分，近义/同类（如"红"与"深红"）得部分分。揭晓时展示"全球答案云"——所有人答案的词频气泡图，让你看到自己是主流还是异类，以及你和搭档各落在哪。连续命中同一搭档积累"心电感应"羁绊值，高羁绊登上"心灵双胞胎榜"。与 Two Truths 相反：这里没有对手，只有共谋，双方目标完全一致。

**分享卡设计**
两种卡。同频卡：两个匿名头像中间一道闪电，"我和一个陌生人同时想到了『星期天是米黄色』"，配全球只有 3.7% 的人这么想的稀有度标签——越小众的共鸣越珍贵越想晒。答案云卡：当日词频气泡图截图，高亮你的答案位置 + 一句"你属于 12% 的少数派"，本身是有趣的社会心理信息图。卡角二维码直达明日同频，扫码匿名入场。

**留存与回访**
天然日更钩子：每天一题，错过即无。羁绊系统提供长期目标——和同一"心灵双胞胎"连续命中，羁绊升级、登榜，制造想回来续命中连击的动力。答案云带来社会比较满足（我是主流还是异类）。可加"重逢机制":高羁绊搭档次日优先重新配对，把匿名陌生人养成一段持续的默契关系。连续答题打卡奖励维持日活。

**技术实现**
前端 Web 单页（答题 + 揭晓动画 + 答案云气泡图）。后端核心是配对与答案归一化。配对：在线玩家进等待池随机两两撮合，人不足时走异步（配上历史答案库里的某人当日答案）。归一化是成败关键：先做基础清洗（去空格/大小写/繁简/同义词典），中文近义靠预建同义词表 + 词向量相似度阈值聚类，把"猫咪/猫/小猫"归一。全球答案云用当日答案实时聚合词频。AI 仅用于离线扩充同义词典和给开放题目做语义聚类，非每次调用，成本可控。数据落 Postgres，当日答案计数用 Redis。

**防滥用/反作弊/内容安全**
最大作弊风险是"两人串通答同一答案刷羁绊"——用随机匿名配对天然对抗（你无法选定搭档），并对异常高频命中的账号对做风控。防"用超冷门私密暗号必中"：可对过度小众且成对出现的答案降权。答案是自由文本，需过敏感词与人身攻击过滤，尤其防有人把答题框当骂人/引流渠道，违规答案不进答案云并封号。异步配对用历史答案时须去身份化，不暴露对方任何信息。

**冷启动与宣发**
冷启动怕"没人配对/答案库空"：开局用官方与内测答案预填历史库，保证异步配对永远有对手，答案云也有内容。宣发主打"你能和陌生人心灵同频吗"——这是天然的情侣/朋友/主播互动测试题，把每日题目本身做成可在评论区参与的社媒话题（"说一个像星期天的颜色，看多少人和你一样"），无需进 App 就能病毒扩散，再导流回站。主播双人连线现场比拼默契，观赏性强。

**盈利模式**
IAA 为主：揭晓答案云前插激励视频——"看广告解锁：查看和你同频的陌生人今天还答了哪些题"或"复活一次错过的连击"。付费点：解锁历史答案云深度数据、心灵双胞胎专属徽章、和高羁绊搭档的"重逢优先权"。适合上微信/抖音小游戏走 IAA 分成，社交测试属性契合平台分享裂变。中长期靠情侣/团队版付费玩法（企业团建默契测试）延展。

**MVP 范围与开发量**
砍到只剩：每日一题 + 随机配对（含异步兜底）+ 答案归一化 + 计分 + 答案云 + 一张同频分享卡。不做羁绊系统、不做双胞胎榜、不做重逢。核心难点是中文答案归一化质量（决定"该算命中却判错"的体验），约 3–4 周一人可出 Demo，同义词典与阈值调优是持续工作量。

**主要风险与化解**
最大风险是归一化误判——"猫"和"猫咪"没判同频会毁掉核心爽感，靠预建同义词表 + 语义聚类 + 人工回补高频词对逐步收敛，宁可放宽也别过严。其次是冷启动配对荒，靠异步历史答案库兜底。第三是题目质量——开放题设计极难，太发散则永远不同频、太收敛则人人命中失去惊喜，需专人打磨题库并按命中率数据动态筛选好题。
