# 原初汤 Primordial Soup

全网仅一片持久化世界池塘：人人用一句话造一个物种投入，服务器每隔几分钟推进生态模拟，AI 以新闻口吻播报涌现事件。你的造物可能变异称霸成全网顶级掠食者，也可能灭绝进入化石档案。

**核心体验与情绪钩子**
一句话造神，然后眼睁睁看它在共享世界里活出自己的命运。钩子是"我的造物成了全网顶级掠食者"的炫耀，与"它灭绝了"的失落——共享单一世界带来的社交涌现与归属感，人人都盯着同一个池塘。

**详细玩法与规则**
全网唯一持久池塘。每人每隔冷却（如 30–60 分钟）用一句话描述一个物种（"怕盐、以荧光为食的半透明虫"），AI 转成属性（食性、耐盐、速度、繁殖率、体型、攻防）投入池中。服务器每几分钟推进一步，结算捕食/竞争/繁殖/变异/灭绝；AI 以新闻口吻播报大事件（"荧光虫种群爆发，吞噬盐藻帝国"）。可查自己血系的种群曲线、变异史与世界排名。

**分享卡设计**
物种名片卡——外观图 + 属性雷达 + "当前排名 X / 全网顶级掠食者"徽章 + 一句高光战报。灭绝则生成"化石档案"卡（墓碑风 + 存活时长 + 巅峰种群）。两种卡各自自带炫耀或悲情，都适合甩群引发讨论。

**留存与回访**
世界持续演化制造"离开一会我的物种怎样了"的牵挂——冷却结束、物种称霸/濒危/灭绝均推送提醒。周榜设"本周霸主""最惨灭绝"；血系可传承变异，长期养成一条属于你的演化谱系。

**技术实现（含 AI 调用成本与延迟）**
两段 AI：投放时"自然语言→结构化属性 JSON"（一次小模型调用，约 $0.001–0.005，可容忍 1–2 秒延迟）；播报时"事件→新闻文案"（攒一批事件一次生成，摊薄成本）。生态模拟是纯服务端定时循环（无 AI），跑规则化的 Lotka-Volterra 变体 + 网格空间，几分钟一 tick，与在线人数解耦。属性抽取尽量缓存去重降本。

**防滥用/反作弊/内容安全**
一句话描述是 UGC——先过文本审核拦违规，再把抽取出的属性钳制在合理区间（属性总点数封顶）防"无敌物种"破坏平衡。冷却 + 每账号限流防刷屏灌满池塘。播报文案生成后再过一遍安全过滤，防 AI 胡说违规内容。物种名去重防冒名。

**冷启动与宣发**
赛道拥挤（Tidepool/Species），差异化死死压在"全网共享同一世界的社交涌现"——别人玩的是自己的沙盒，我们是大家共同争夺的唯一池塘。宣发靠"新闻播报"自身的观赏性做短视频连载（"今日池塘战报"），以及"帮我的虫子点赞、别让它灭绝"的社群拉票。

**盈利模式**
激励视频最实——"缩短冷却/给物种一次变异/复活灭绝血系"看广告（IAA 分成 50%）。Web 端战报页挂 AdSense 并吃 SEO 长尾（物种页、战报页）。付费点须克制，绝不卖"氪金无敌物种"以免毁掉共享世界的公平，可卖纯外观皮肤。AI 与模拟服务器是固定成本，需用日活与广告严格覆盖。

**MVP 范围与开发量**
先做单池塘 + 文字属性抽取 + 每 5 分钟一 tick 的简化生态（捕食/繁殖/灭绝三条规则）+ 基础新闻播报 + 种群曲线，外观先用程序化生成或表情符号占位。1 名全栈 + 模型调用约 3–5 周。空间/变异/血系树后置。

**主要风险与化解**
风险一，赛道同质化——所有设计资源压在"唯一共享世界"体验上，其余砍掉。风险二，模拟失衡（一物种秒杀全场或全灭）——属性钳制 + 周期性环境事件（涨盐、降温）重置平衡。风险三，AI 属性抽取不稳定——强制结构化输出 + 校验 + 失败回退默认值。风险四，服务器持续成本——模拟与 AI 解耦、批量播报、按活跃度弹性伸缩。
