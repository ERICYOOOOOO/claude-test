# Infinite Wiki 无限维基

打开是一部虚构宇宙的维基百科。每篇文章里都埋着红链（尚未创建的词条），你一点，AI 当场生成一篇内部自洽的新词条——而且它从此对全世界永久存在、被后来所有访客共享。全网合力，织出一部越来越自洽、越来越庞大的假百科。

**核心体验与情绪钩子**
无限探索的多巴胺：每个红链都是一扇没人开过的门，点开就有一整篇新世界。钩子是"我是第一个发现并定稿这个词条的人"——集体建造 + 探索发现 + 你的点击在这部百科里留下永久痕迹。越读越觉得这个假宇宙"真的存在"，因为它自我引用、彼此印证。

**详细玩法与规则**
每篇词条含正文 + 若干内链（已存在，蓝）和红链（未生成）。点红链：若已被他人生成则直接跳转（共享），否则触发 AI 实时生成——喂入当前词条上下文 + 该假宇宙的世界观设定 + 若干相邻词条摘要，产出一篇 300-600 字、风格统一、并主动埋入 3-8 个新红链的文章，写库后对全球可见。首个点击者记为该词条"定稿人"。生成耗时目标 3-8s，期间显示"正在从虚空中考据…"占位动画。可加轻量编辑：登录用户可补充段落（进入版本历史）。顶部显示"你已定稿 X 个词条"与全站总词条数、贡献榜。

**分享卡设计**
一张仿维基信息框卡：顶部假词条标题（如"雾钟教团"）+ 一句摘要，中部一张 AI 生成/占位配图或信息表，底部"由你定稿 · 全站第 12,847 篇 · 链入 6 篇"，配短链。零剧透因为它只露标题与一句引子，勾人却不剧透正文；想炫是因为"我定稿了这个词条""这个假宇宙里有我写下的一页"是独特的创作署名感。可分享"我发现的最离奇词条"合集。

**留存与回访**
探索本身高留存（红链无限）。回访钩子：贡献榜与"定稿数"成就；订阅"你定稿的词条被链入了 N 次""有人续写了你的词条"通知，制造被引用的荣誉。定期高亮"本周最自洽/最离奇词条"策展。SEO 是隐性回访：海量长尾假词条被搜索引擎收录，持续带来新访客与老访客回流。

**技术实现**
前端静态站 + 词条页服务端渲染（利于 SEO）。后端：词条库（Postgres，正文 + 红蓝链图 + 定稿人 + 链入计数）；红链点击走生成队列，调 LLM（带世界观 system prompt + RAG 检索相邻词条做上下文，保证自洽）。生成结果落库并缓存/CDN，之后为纯静态读取。需要向量库存词条 embedding 供检索与去重。扩容成本主要是 LLM 调用：写一次、全球读无数次，边际成本低；用生成队列 + 速率上限 + 结果永久缓存控制账单。参考 Neal.fun 量级，纯展示广告需数百万月访才够，故成本控制是生死线。

**防滥用/反作弊/内容安全**
生成侧：system prompt 约束题材，输出过内容审核（暴力/色情/真实人物诽谤/现实政治敏感），命中则重生成或拒绝。防刷：红链点击限速、生成需登录或过人机验证，避免恶意刷爆 LLM 账单（这是主要成本攻击面）。防污染：编辑进版本历史可回滚，低质/离题词条可被折叠或标记；用相似度去重防重复词条。可加社区举报 + 轻量人审队列。

**冷启动与宣发**
预生成一个有钩子的种子宇宙（几百篇，设定统一、埋满诱人红链），让首批用户一进来就"根本停不下来"。宣发主打"建造故事"与截图："我们在用 AI 集体写一部假维基，现在已经 X 万篇且自洽得可怕"。鼓励用户晒最离奇词条、晒自己的定稿数。可与特定同好圈（TRPG、克苏鲁、SCP 风）联动做主题宇宙引爆。

**盈利模式**
现实判断：这是三个点子里最有长线变现潜力的。① SEO 长尾：海量词条吃搜索流量，配展示广告（$1-3/千次浏览，需规模）。② 订阅：Pro 去广告 + 更高生成配额 + 私有/主题宇宙 + 编辑权限，用工具类订阅逻辑吃真实付费意愿。③ 授权/API：把"自洽世界生成"能力卖给游戏/写作团队。务实预期：广告养成本、订阅养利润，早期靠订阅比靠广告更快回正，且必须先压住 LLM 成本。

**MVP 范围与开发量粗估**
MVP = 词条阅读 + 红链实时生成并落库共享 + 定稿人记录 + 基础内容审核 + 分享卡。砍掉编辑/版本、向量检索（初期用父词条上下文即可）、通知、订阅。一名全栈约 1.5-2 周：词条库与页面渲染 3 天、生成管线与 prompt 调优 3-4 天、红蓝链解析与落库 2 天、审核与限速 2 天、分享卡与贡献榜 1 天。

**主要风险与化解**
① LLM 成本失控（被刷或病毒式增长烧钱）：登录/验证码 + 限速 + 永久缓存 + 生成配额，把"写一次读无数次"落实。② 自洽性衰减（越写越矛盾）：RAG 检索相邻词条 + 强世界观约束 prompt + 去重，必要时人工/模型定期"考据校对"。③ 内容安全与版权（生成影射真实人物/作品）：审核层 + 题材白名单 + 免责声明与举报回滚。
