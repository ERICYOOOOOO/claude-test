# 心电图 Flatline — 计划书 & Playbook

> 每日一局 45–60 秒的"稳住"挑战。系统逐拍采样你的微反应，最后渲染成一条以假乱真的生命体征线。
> 稳的人晒一条高冷平线，崩的人晒"⚠ CODE BLUE · 第 7 拍"。两种结果都想发出去。

- 本体：`index.html` + `style.css` + `app.js`，纯静态零依赖，file:// 可开，单页总重 < 150KB。
- 本文件是数值与视觉的**唯一事实源**，代码实现必须与此一致；调手感先改这里再改代码。

---

## 1. 体验支柱

1. **像一台真的监护仪**——不是"医疗主题网页游戏"，是一台开机的机器。所有 UI 元素（BPM、扫描线、波形余晖、报警声）都必须能在真监护仪上找到原型。
2. **压力是设计出来的**——三段递进（平稳→施压→暴走），玩家在 45 秒内被推入轻微生理唤醒，然后被镜子照见。
3. **分享卡零剧透**——卡面只暴露"第几拍崩、崩多惨"，不出现任何玩法说明。看的人只能点进来自己试。

## 2. 逐屏用户旅程

### 2.1 首访（D1，从未玩过）

| 步骤 | 屏 | 内容与目标 |
|---|---|---|
| 1 | 开机屏 | 监护仪已"上电"：顶栏 FLATLINE #期号、静音开关；ECG 条实时跑一条 62 BPM 的窦性闲置线（余晖拖尾）；中央只有两行：`今日监护 #4` 与 `按下任意处 开始`。无说明书、无 feature 列表。 |
| 2 | 过场 | 按下后 600ms "开始监护" 过场（扫描亮线掠过），直接进拍 1。 |
| 3 | 拍 1（教学） | 永远是慢速 TAP（4200ms），判定条上方一行提示：`光标过线的瞬间 · 点`。这是全游戏唯一一句教学，之后消失。 |
| 4 | 拍 2–5（平稳段） | 正常速度 TAP/HOLD，最多 1 个 WAIT。每拍结束闪判定词（稳/微颤/手抖/失控）+ ECG 上打出对应波形。 |
| 5 | 拍 6–10（施压段） | 屏幕轻微摇晃（±1.6px）、假提示 WAIT 增多、外围干扰闪烁出现。BPM 数字随失误上升。 |
| 6 | 拍 11–14（暴走段） | 节奏加快（拍长 -30%）、摇晃加强（±3px）、干扰密集。 |
| 7a | CODE BLUE | 连续 3 拍 <30 分：当场终止。全屏红脉冲 ×3 + 报警长鸣，ECG 炸尖峰后拉平，1.4s 后进结算。 |
| 7b | 正常结束 | 第 14 拍判定后 800ms，"监护结束"一闪，进结算。 |
| 8 | 结算屏 | 大 ECG 结果波形（发光+余晖质感）横贯卡面；状态戳盖章动画（RESTING / CODE BLUE·第 N 拍 / FLATLINE MASTER）；镇定指数 NN/100；连稳天数；按钮：`复制战报` `存图` `练习模式`；下一期倒计时；底部极简自推广位（AdSense 挂点）。 |
| 9 | 分享 | 复制 → 文本战报进剪贴板，按钮变"已复制"；存图 → canvas 导出 PNG 下载。 |

### 2.2 回访（D2+）

- 开机屏顶部多一行：`已连稳 N 天 · 最佳 M`。有连胜的人损失厌恶拉满。
- 打完当天：开机屏切换为"今日已完成"态——迷你结果波形 + 状态戳 + 分享按钮 + `练习模式`（不计连胜、不入历史）+ 下一期倒计时。
- 跨午夜刷新：以本地日期为准换题，与 Wordle 一致。

### 2.3 失败者路径（重点设计）

CODE BLUE 不是惩罚屏，是**素材生产屏**：崩拍尖峰在卡面上又大又红又好笑，配文钩子（"第 7 拍"）现成。结算屏文案干燥不安慰：`记录已存档。明天的第 7 拍在等你。`

## 3. 玩法数值表（唯一事实源）

### 3.1 拍序生成（每日种子）

- `dayIndex = Math.floor((Date.now() − tzOffsetMin×60000) / 86400000)`（本地日期，全球同题）。
- 期号 `issue = dayIndex − 20635 + 1`（2026-07-01 = #1）。
- PRNG：mulberry32(dayIndex)。练习模式：随机种子，界面标"练习"，不入连胜/历史。
- 拍序模板（种子内洗牌）：

| 拍 | 池 | 约束 |
|---|---|---|
| 1 | TAP（教学，固定） | 4200ms 慢速 + 提示行 |
| 2–5 | [TAP, TAP, HOLD, (30% WAIT / 70% TAP)] | 洗牌后拍 2 不得为 WAIT |
| 6–10 | [WAIT, WAIT, HOLD, TAP, TAP] | 洗牌 |
| 11–14 | [WAIT, HOLD, TAP, TAP] | 洗牌 |

合计：TAP 7–8、HOLD 3、WAIT 3–4。

### 3.2 节奏 / 时窗

| 参数 | P1 平稳(1–5) | P2 施压(6–10) | P3 暴走(11–14) |
|---|---|---|---|
| TAP 拍长 | 3000ms（拍1: 4200） | 2600ms | 2100ms |
| TAP 目标点位置 | 拍长 × (0.58–0.74，种子随机；拍1 固定 0.62) | 同左 | 同左 |
| HOLD 按住时长 H | 1500ms | 1300ms | 1100ms（各 ±100ms 种子随机） |
| HOLD 提示出现 | 拍开始 +300ms | 同左 | 同左 |
| WAIT 拍长 | 2600ms | 2400ms | 2000ms |
| 拍间隔（判定词展示） | 500ms | 420ms | 320ms |
| 屏幕摇晃 | 0 | ±1.6px / ~6Hz | ±3px / ~9Hz |
| 外围干扰密度 | 0 | 每拍 0–1 个 | 每拍 1–3 个 |

一局总时长 ≈ 45–58 秒（HOLD 拍为动态长度：按下时刻 + H + 700ms）。

### 3.3 判分公式（每拍 0–100 镇定分）

**TAP**（err = |按下时刻 − 目标时刻| ms）
- err ≤ 70 → 100（完美）
- err > 70 → `max(6, round(100 − (err−70) × 0.21))`（200ms→73，300ms→52，460ms→18）
- 整拍未按 → 4
- 无效连点（同拍第 2 次起）：每次 −12，最多计 4 次

**HOLD**（cue = 提示出现时刻）
- 提示前抢按：每次 −12（最多 2 次），不算作起按
- 迟疑罚：h = 首次按下 − cue；`max(0, h−450) × 0.08`，上限 35；cue 后 1600ms 仍未按 → 整拍 5 分
- 释放罚：errR = |松手 − (按下+H)|；`max(0, errR−120) × 0.15`，上限 55
- 提前松手（早于目标 350ms 以上）额外 −10
- 抖动（松手后再按）：每次 −15，最多 2 次
- 得分 = `clamp(100 − 各罚项, 0, 100)`；到拍尾仍未松手按 errR=700 计

**WAIT**
- 全程忍住 → 100
- 点了 → `max(0, 8 − 4 × (点击次数 − 1))`（重罚）

### 3.4 判定词 / 成败

| 分数 | 判定词 |
|---|---|
| ≥85 | 稳 |
| 60–84 | 微颤 |
| 30–59 | 手抖 |
| <30 | 失控 |

- **CODE BLUE**：连续 3 拍 <30 → 当场终止，failBeat = 当前拍号。
- **FLATLINE MASTER**：14 拍全部 ≥85（稀有勋章，金绿戳）。
- **RESTING**：完赛且非 MASTER。
- **镇定指数** = 已进行拍的分数均值（四舍五入）。
- 连稳天数：RESTING/MASTER +1；CODE BLUE 归零；漏一天归零。

### 3.5 BPM 演出（纯展示）

`bpm = round(62 + 34 × avg(最近3拍 (100−分)/100) + 阶段×3)`，CODE BLUE 后跳 0 并显示 `---`。闲置/开机屏恒 62。

## 4. 动效表（全部指定时长/缓动，只动 transform/opacity）

| 动效 | 触发 | 时长 | 缓动 | 说明 |
|---|---|---|---|---|
| 开机过场 | 开始按下 | 600ms | cubic-bezier(0.16,1,0.3,1) | 亮线自上而下扫过 + 屏幕亮度脉冲 |
| TAP 光标扫动 | 每 TAP 拍 | =拍长 | linear（rAF 驱动 translateX） | 2px 发光竖线 |
| 按下即时反馈 | 任意输入 | ≤100ms | — | ECG 打点 + 判定区 120ms 亮闪（opacity） |
| 判定词浮现 | 拍结束 | 240ms | ease-out | 上移 8px + 淡入，驻留至拍间隔结束 |
| 崩拍红闪 | 分 <30 | 180ms | ease-out | 全屏红 vignette 一闪 |
| WAIT 假提示脉冲 | WAIT 拍 | 700ms 循环 | ease-in-out | 红/琥珀交替闪 opacity |
| 屏幕摇晃 | P2/P3 | 持续 | rAF 正弦 | 只动 monitor 容器 transform |
| CODE BLUE 脉冲 | 失败 | 900ms ×3 | ease-in-out | 全屏红 overlay opacity 0→0.35→0 |
| 结算盖章 | 进结算 300ms 后 | 320ms | cubic-bezier(0.34,1.56,0.64,1) | scale 1.6→1 + 旋转 −4° |
| 按钮反馈 | hover/active | 160ms | ease-out | 边框亮度 + translateY(1px) |
| 已复制确认 | 复制成功 | 1600ms 驻留 | — | 按钮文字替换 |

`prefers-reduced-motion: reduce`：摇晃、扫描线纹理、假提示闪烁、干扰闪烁、红脉冲全部移除；ECG 波形（核心信息）保留；盖章改为无缩放淡入。

### 5.2 字体 / 字阶（1.25 模数，基准 15px）

## 6. 声音设计（WebAudio 合成，首次交互后启动，右上角静音，默认开）

| 音 | 触发 | 合成 |
|---|---|---|
| 心跳 lub-dub | 游戏中每拍起始 | sine 62→40Hz 两声 90ms，间隔 120ms，gain 0.22；P3 音量 +20% |
| 命中 | TAP/HOLD 按对 | square 880Hz 60ms，完美加 1320Hz 泛音一声 |
| 失误 | 分 <60 的输入 | sawtooth 110Hz 160ms |
| WAIT 中招 | WAIT 被点 | 噪声 buzz 220ms + 低鸣 |
| CODE BLUE | 失败 | 740Hz 长鸣 600ms ×3（监护仪报警） |
| 结算 RESTING | 完赛 | 两音上行 660→880Hz 各 120ms |

## 12. 手感调参旋钮（改数值先看这里）

| 症状 | 旋钮 |
|---|---|
| 太简单、人人 MASTER | TAP 完美窗 70→50ms；P3 拍长 2100→1900；MASTER 线 85→88 |
| 太难、CODE BLUE 率 >40% | 失控线 30→25；P2 摇晃 1.6→1.2px；WAIT 罚分 8→20 |
| WAIT 不骗人 | 假提示样式加"伪光标扫动"权重；P2 WAIT 提前到拍 6 首位 |
| 没有压力感 | 心跳音量随阶段 +；P3 拍间隔 320→260ms；BPM 数字变红阈值下调 |
