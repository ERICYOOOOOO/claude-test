# 每日一法 Daily Law · PLAYBOOK

> 像「每日诗词」那样，每天呈现一条值得一读的法律条文。七个法域，每天各一条。
> 本文件即策划案：定位、选材标准、内容规划、逐屏旅程、视觉与动效规格、分享卡规格、发布 checklist、运营节奏。

---

## 一、产品定位：为什么「法条日历」会被转发

**引用型内容 + 日期仪式感**，是中文互联网被验证过最久的两种传播机制的叠加：

1. **引用型内容自带转发理由。** 「人的尊严不可侵犯」「天体不得据为己有」「玩是写进国际法的权利」——法条是被国家机器背书过的金句。转发一条法条，比转发一段鸡汤更有分量，比转发一篇长文更省力。用户转发它时，表达的是自己的立场与品位，这是分享行为的第一驱动力。
2. **日期仪式感制造回访。** 单向历翻了十年还在被买，因为「今天这一页」是一种低成本的日常仪式。每天全球同一页（本地日期种子），错过即翻篇（只保留昨日回看），稀缺性由日历结构天然给出，不需要运营制造。
3. **法律科普是长期缺口。** 法学生、公考人群、普法工作者、时事围观者，都长期需要「一条一条、有出处、可核验」的法条素材。市面上多是长文解读或碎片截图，缺一个克制、准确、好看的**条文本体**产品。

一句话定位：**可以裱起来的法条日历。** 不解读热点、不做立场输出，只做「条文本体 + 出处 + 一段克制的手记」。

## 二、选材标准（全文）

收录一条法条，必须同时满足：

1. **真实存在。** 现行有效，或作为历史文献仍具法律/宪制意义（如《大宪章》1215、《1848 年废奴法令》）。虚构、传言、段子式「法条」一律不收。
2. **可公开核验。** 官方公报、政府法律数据库、联合国条约库等公开渠道可查原文。出处必须写全：法典/条约名 + 条款号 + 生效（或通过/颁布）年份。
3. **有故事性或现实关照。** 至少占其一：历史转折点（德国基本法第一条）、意外的起草故事（日本宪法第二十四条）、与当下生活直接相关（七日无理由退货、家务劳动补偿）、认知反差（「玩」是国际法权利、月球不得据为己有）。
4. **一屏能读完。** 节选控制在约 120 字以内；长条文取最有力的款项，节选须保持原意完整，不断章取义。
5. **准确性红线。** 中文轨用官方原文；外国轨用通行中译并注明原语言与原文名（联合国文书优先采用官方中文作准文本）。表述拿不准的、译本有争议且无通行本的，**不收**。法律条文本身属公有领域，手记为原创。
6. **克制红线。** 手记 60–120 字，讲历史脉络或现实意义，不煽情、不站队、不蹭热点人名。能砍的字都砍。

### 数据字段

```js
{
  track: 'cn',            // 轨道 id
  text: '……',             // 条文节选（忠实原文/通行译本）
  source: '《…》第…条',    // 法典/条约名 + 条款号
  enact: '2021年施行',     // 生效/通过/颁布年份
  origLang: '德语',        // 外国轨/条约轨必填：原语言
  origName: 'Grundgesetz, Art. 1(1)', // 外国轨/条约轨必填：原文名
  note: '……',             // 编辑手记 60–120 字
  dateOverride: '12-04'   // 可选：MM-DD，命中当天该轨优先展示本条（应景机制）
}
```

### 选条算法

- 每日种子：`seed = floor((now − tzOffset) / 86400000)`，以用户本地日期为准，全球同一天同页。
- 常规日：`pool[(seed + trackSalt) % pool.length]`——顺序轮转，保证相邻两天同轨必不相同。
- 覆盖日：当天 `MM-DD` 命中该轨某条的 `dateOverride`，该条优先（详见「运营节奏」）。
- 覆盖日两侧防重复：覆盖日前一天轮转位若恰为覆盖条，顺延一位（`idx+1`）；覆盖日次日轮转位若恰为覆盖条，改用前一天被覆盖跳过的轮转条（`idx-1`）。单步前后看、确定性不变，「昨日回看」逻辑一致，保证同一条不会连续两天出现。
- 昨日回看用 `seed − 1` 与昨日的 `MM-DD` 计算，逻辑一致。

## 四、逐屏旅程

1. **首屏（0 说明书）**：顶栏「每日一法 + 七轨切换 + 收藏夹」；主体是一张日历页——朱砂装订条与装订孔、极大日期数字、星期、居中大字条文、出处、置底编辑手记、三个操作（收藏/复制引用/存图分享）。第一眼即懂：这是今天的一页。
2. **切轨**：点「美国」，日历页向上翻出、新页翻入（240ms）。同一天七页不同内容，探索成本为零，这是第一次交互教学。
3. **昨日回看**：右上「看昨日」→ 出现朱砂「昨日」标签，按钮变「回到今天」。只有一天，制造「翻篇」的日历感，不做无限档案。
4. **收藏**：点「收藏」变朱砂底「已收藏」，顶栏收藏夹计数 +1。收藏夹面板列出条文摘录 + 轨道 + 出处，可移除。localStorage 持久化，损坏数据自动回退。
5. **复制引用**：一键复制纯文本（【每日一法】日期·轨道 + 「条文」 + 出处 + 原文名 + 域名），toast 反馈「已复制」。
6. **存图分享**：弹层预览 canvas 分享卡，可下载 PNG 或复制文本版。
7. **页脚**：一行免责声明（科普节选，不构成法律意见，条文以官方最新版本为准）+ 域名。免责声明是法律科普产品的合规底线，永远保留。

空状态：收藏夹空时给一句引导。错误态：剪贴板不可用时降级 execCommand 并提示。加载态：纯内嵌数据无加载。

## 五、动效与视觉规格

**艺术方向：单向历 / 碑帖。** 整页像一张可以裱起来的日历。

- 配色：纸白 `#faf7f0`、碑墨 `#1c1a17`、朱砂印 `#b02e24`；辅助墨 `#57524a`、淡墨 `#8b857a`、发丝线 `#ddd6c8`。禁止渐变、玻璃拟态、圆角阴影全家桶。
- 字体：系统衬线栈 `Georgia / Songti SC / Noto Serif CJK SC / SimSun`。零外部字体。
- 字阶（1.25 模数近似）：日期数字 `clamp(100px, 22vw, 156px)`；条文 `clamp(21px, 2.7vw, 33px)`（桌面 28–36 区间）行距 1.95；出处 15px；手记 14px 行距 1.9；眉题/标签 11–13px 大字距。
- 间距：4/8px 体系；日历页内边距移动 40/24、桌面 56。
- 翻轨动效：`rotateX(−10deg) translateY(−14px) + opacity`，120ms 出 + 120ms 入（合计 240ms），缓动 `cubic-bezier(0.16, 1, 0.3, 1)`，transform-origin 顶端——纵向翻日历感。只动 transform/opacity，60fps。`prefers-reduced-motion` 降级为 150ms 淡入淡出。
- 微反馈：按钮按下 `translateY(1px)`；轨道切换朱砂圆点 200ms 缩放；toast 200ms 淡入，1.6s 后淡出。所有输入反馈 <100ms 内可见。
- 可访问性：tablist/tab 语义、aria-pressed、aria-live、焦点朱砂描边、触控目标 ≥44px、375px 无横向滚动。

## 六、分享卡规格

canvas 720×1200，单向历构图，纯绘制（零外部资源，file:// 不污染画布）：

1. 纸白底 + 外粗（3px）内细（1px）碑墨双框 + 顶部朱砂装订条（8px）。
2. 眉题：`每 日 一 法 · 轨道名`，24px 辅助墨。
3. 大日期：210px 衬线数字；下一行 `YYYY年M月 · 星期X` 26px。
4. 分隔短线 + 朱砂方点。
5. 条文：自适应字号 40→22px（按行数收缩），行距 1.9，逐字换行（CJK），居中。
6. 出处小字 22px（含生效年份）。
7. 底部朱红印章：92×92 圆角方印，微旋 −2°，白字「每日/一法」2×2；印下域名 `meiriyifa.app` 20px。

文本版（复制引用同款）：

```
【每日一法】7月4日 · 国际条约
「不实际参加战事之人员……在一切情况下应予以人道待遇。」
——《日内瓦四公约》共同第三条（1950年生效）
原文：Geneva Conventions of 1949, Common Article 3（法、英作准文本）
meiriyifa.app
```

零剧透（法条不怕剧透，卡面即全部）、有炫耀点（今天读了哪国哪条）、带回流位（域名）。

### 周节奏

- **第 1 周｜冷启动**：上线 + 自测复跑；小红书发 3 张「今天这条法律你知道吗」卡（选认知反差最强的：外空条约、玩的权利、死刑废止四词）；知乎/即刻各一篇「我做了一个法条日历」制作记。
- **第 2 周｜渠道铺开**：小红书日更卡片矩阵（详见 MARKETING.md）；微博建「#每日一法#」话题日更文本版；投 2–3 个法学生 QQ/微信群与公考社群做种子用户，收集「你希望上日历的一条法」。
- **第 3 周｜共创与节点**：采纳社群投稿 5–10 条入库（走选材标准 + 测试）；赶最近的普法节点做一次 dateOverride 预热推送；联系 1–2 位 B 站法律区 up 谈「视频末尾今日一法」口播位。
- **第 4 周｜复盘定型**：看回访率与收藏率定轨道增删；确定「每周补 3–5 条」的常态扩库节奏；启动变现挂点观察（自推广位 → AdSense 切换标准见 DEPLOY.md）。

### 长期内容池纪律

- 每条新入库必须过 `data.mjs`；出处存档一份核验链接（内部维护，不上页面）。
- 法律修订跟踪：每季度复核一遍在库条文是否被修正/废止；修订的条文更新文本或移库并在手记注明年代背景。
- 手记不追热点事件、不点评在审案件——这是普法产品的安全边界，也是格调。
