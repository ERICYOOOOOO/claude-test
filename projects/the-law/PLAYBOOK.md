# 今日之律 The Law — 计划书 & Playbook

> 每天全球一条隐藏法则，作用于数字三元组 (a, b, c)，1–20。
> 你提交实验换 ✓/✗，归纳出规律，然后接受终审。用的实验越少，越体面。

- 目录：`projects/the-law/`
- 形态：纯静态单页（index.html + style.css + app.js），零依赖，file:// 可直接打开
- 艺术方向：**实验室档案 / 公文卷宗**——你在往一份保密卷宗上盖章，直到它招供
- 上线纪念日（第 1 期）：2026-02-13（本地日序号 20497）；期号 = 本地日序号 − 20497 + 1

## 一、逐屏旅程

### 屏 0 · 卷宗落桌（首屏，无说明书）

打开页面即是当日卷宗，没有开屏页、没有教程弹窗。

- 桌面深色（#20242e），纸面 #f4f1e8 卷宗居中（≤660px），移动端纸面铺满。
- 眉头：左「今日之律 / THE LAW」（衬线），右「连胜 n」。
- 卷宗抬头：`卷宗 № 0142`、日期 `2026 · 07 · 04`、难度圆点（●○○ / ●●○ / ●●●）。
- 法则行：`本期法则：` 后面是一条**涂黑遮蔽条**（▓▓▓▓）。这就是全部悬念——法则存在，但被涂黑了。
- 实验台：三个数字格（a · b · c，各带 ▲/▼ 步进和直接输入），「提交实验」主按钮，「参加终审」次按钮。
- 内嵌示例提示（仅首次实验前显示，一行）：
  `例：先提交 2 · 4 · 6——档案会盖章告诉你它合不合法。`（致敬 Wason 2-4-6）
  第一次提交后永久消失（含刷新，随当日进度持久化）。

### 屏 1 · 实验循环

1. 调三个数 → 点「提交实验」。
2. <100ms 内：记录行插入台账顶部，✓（墨绿）或 ✗（印泥红）大戳**从上方落下**盖在行上：随机 ±3° 旋转 + 90ms squash + 纸面微震。
3. 台账表：`序号 | 样本 | 判定`，等宽数字，最新在最上。
4. 重复提交同一三元组：不盖新章，在实验台下方给一行干燥提示「这组已实验过（№ 03），不再计次」。连点节流 250ms。
5. 实验次数无上限，但每一次都写进战报——成本感来自分享卡，不来自惩罚。

### 屏 2 · 终审确认（一次性门）

点「参加终审」→ 实验台原位换成确认卡：

> 终审共 8 题：由你来裁定每个样本是否合法。开始后不能再回来做实验。
> [开始终审] [再想想]

0 次实验也允许直接进终审（有胆量的人应当被允许莽）。

### 屏 3 · 终审（8 题逐一裁定）

- 每题一张大样本卡（如 `7 · 3 · 12`，等宽大字），下方两枚章垫按钮：「✓ 合法」「✗ 非法」。
- 点选后立刻揭晓：**真实判定**的章落在样本卡上（同一套盖章动画），下方小字「判对」/「判错」，累计进度点亮。
- 800ms 后自动进下一题（reduced-motion 下 200ms）。
- 8 题 = 由当日种子确定性生成的 4 正例 + 4 负例，负例优先取"近失变体"（见算法节），顺序被种子洗牌。

### 屏 4 · 结案

- 判决大戳砸下（同盖章动画，尺寸放大）：
  - 8/8 → `CRACKED`＋副行「完美破解」
  - 7/8 → `CRACKED`＋副行「破解成功」
  - 5–6/8 → `PARTIAL`＋副行「部分破译」
  - ≤4/8 → `FAILED`＋副行「未破解」
- 法则遮蔽条揭开，露出今日法则原文（如「三个数的极差不小于 10」）。
- 战绩行：`9 次实验 · 终审 8/8`；连胜更新（≥7/8 续、否则清零）。
- 分享区：文本战报预览 + 「复制战报」；canvas 图卡预览 + 「保存图卡」。
- 「距下一期 hh:mm:ss」倒计时（明天再来的钩子）。
- 「往期档案」入口（当日完成后解锁）。
- 极简自推广位（AdSense 挂点，注释说明激活方法）。

### 屏 5 · 往期档案（练习模式）

- 列表：`№ 0001 · 2026-02-13 · 未挑战 / 已破解 / 未破解`，倒序。
- 点开任意一期 → 完整同一套流程，顶部常驻米黄横幅「练习 · 卷宗 № 0031 · 不计连胜」。
- 练习成绩写入历史（标记 practice），不影响连胜；「返回今日」随时可退。

### 跨屏细节

- 午夜换刊：页面停留跨日后，任何交互或 visibilitychange 检测到日序号变化 → 顶部横幅「新一期卷宗已送达」＋刷新按钮。
- 当日进度（实验台账、终审进行到第几题）实时持久化，刷新不丢。
- localStorage 损坏：try/catch + 版本号 + 字段逐项校验，任何异常回退默认值，绝不白屏。

### 难度曲线

`TIER_BY_WEEKDAY = [2,1,1,2,2,2,3]`（索引 0=周日）：周一/二 → 一档，周三至周五、周日 → 二档，**周六 → 三档（地狱日）**。周一最易、周六最难。

### 每日选择算法

```
day   = floor((Date.now() − tzOffset·60000) / 86400000)   // 本地日序号，全球同一天同题
rng   = mulberry32(hash(day))
tier  = TIER_BY_WEEKDAY[(day+4) mod 7]
pool  = RULES.filter(tier)
tpl   = pool[floor(rng()·len) mod len]      // 循环取模，任意 day（含 376 天后）恒有效
param = tpl.params[floor(rng()·len) mod len]
```

判定器 `pred(triple, param) → bool` 是唯一真理源：实验盖章、终审出题、终审判卷全部调用同一个函数。

## 三、终审出题算法

输入：day。输出：8 道题（三元组＋标准答案），**纯由种子决定，与玩家行为无关，全球一致**。

1. 用与选题不同的种子流 `rng2 = mulberry32(hash2(day))`。
2. **4 个正例**：拒绝采样——随机生成三元组，`pred=true` 且未重复则收下；示例提示 (2,4,6) 排除在题面外。
3. **4 个负例（覆盖易混边界）**：前 60 次尝试用**近失变体**——取已选正例，随机一个分量 ±1/±2（夹在 1..20），若 `pred=false` 则收下。近失变体天然落在规则边界上（递增规则会产出"相邻相等"，极差规则会产出"恰好超一格"），专打玩家最容易归纳错的模糊地带。近失取不满时回退随机负例。
4. 兜底：拒绝采样超限后按全域顺序扫描补齐（密度红线保证 800+ 个正例与负例恒存在，兜底在 376 天回归测试中从未触发）。
5. Fisher–Yates 洗牌（同 rng2），正负例位置不可预测。
6. 判卷：玩家答案逐题与 `pred` 输出比对。≥7/8 破解，8/8 完美。

不变式（test/rules.mjs 断言）：8 题互异、值域 1..20、恰 4 正 4 负、标签与判定器一致、同种子两次生成逐位相同。
