# 每日一人 · PLAYBOOK（即策划案）

一部每天只翻开一页的人物辞典。每天全球同一位名人/历史人物，玩家只能问**是/否问题**，
看几问能把 TA 从一百多人的辞典里揪出来。纯静态、零依赖、零托管成本，遵循
`projects/QUALITY_BRIEF.md` 全部红线。

---

## 一、定位与核心循环

### 目标用户

- **知识型休闲玩家**：玩 Wordle/汉兜的那批人，喜欢每天一局、两分钟内有输赢；
- **文史爱好者**：为揭晓页那 200 字小传和墓志铭而来，猜谜只是入口；
- **群聊话事人**：需要每天往微信群/朋友圈扔一个能引战的小话题——"我 4 问猜出来了，你呢"。

### 核心循环（每天 2–5 分钟）

1. 打开即是问题索引，无说明书：第一次点击"TA 还在世吗？"，落章"否"，玩法即已教会；
2. 五类索引签（时代/地域/领域/身份/生平）逐步缩小包围圈，每问计一次；
3. 随时在搜索框猜人名（支持别名/英文名/编辑距离容错），猜错也计一次并提示"不是 TA"；
4. 猜中 → 翻到**辞条页**：首字纹章、生卒年（en-dash）、150–250 字小传、一句墓志铭；
5. 复制文本战绩 / 存 PNG 分享卡（零剧透）→ 倒计时钩子"下一位人物 HH:MM:SS 后揭榜"；
6. 意犹未尽 → 往期档案练习（不计连胜）。

### 为何会传播

- **战绩可炫耀且零剧透**：轨迹格 🟦🟥🎯 像 Wordle 色块，别人看得懂"7 问破解"的含金量，
  却不知道答案是谁——好奇心直接导流；
- **同题社交**：全球同一天同一人，群里可以互相报问数、抬杠"你居然 15 问"；
- **内容自带二次传播点**：揭晓页的小传是可截图转发的独立内容（"原来蔡伦是这么死的"）；
- **每日仪式感**：连胜数字 + 午夜换人，标准 daily 游戏留存钩子。

## 三、人物库收录标准

现库 **111 人**：中 44 / 外 67（约 4:6）。领域分布：政治军事 22、科学 18、文学 19、
艺术 11、演艺 13、思想 10、体育 9、探险 9；女性 14。

### 收录三原则

1. **辨识度**：受过义务教育的中文玩家听到名字应有"哦，是 TA"的反应，冷门学术名人不收；
2. **属性无歧义**：全部 25 个属性（含 19 个布尔）必须能按下述口径给出唯一答案，
   **拿不准的人不收**（例：本杰明·富兰克林的主领域科学/政治说不清，不收；
   李小龙国籍归属有争议，不收；老子生卒无信史，不收）；
3. **生卒年可靠**：允许"约"（如庄子、蔡伦），但误差不得跨越任何时代题阈值
   （前 0/1000/1500/1800/1900/1950/2001）。

### 判定口径（与题库一字对应）

- **country**：出生与文化认同的祖国，只记一个（特斯拉记塞尔维亚、爱因斯坦记德国、
  居里夫人记波兰）；归化不改 country，只置 `emigrated`；
- **head**：实际担任过元首或政府首脑，含帝王、总统、总理、宰相（诸葛亮、曹操算，
  邓小平不算——他从未任元首或总理，这是刻意保留的好问题）；
- **military**：史实上亲自统率过军队作战（丘吉尔在一战率过营，算；秦始皇未亲征，不算）；
- **painter / poet / actor / singer**：以该身份为主要事业之一（苏轼会画画但不算画家；
  猫王演过 31 部电影，算演员）；
- **violentDeath**：他杀/处决/战死/自杀/重大事故/药物急性中毒，在世者一律 false；
- **imprisoned**：因政治或司法被监禁、软禁、流放、贬谪（伽利略软禁算、苏轼贬谪算；
  图灵获缓刑未入狱，不算）；
- **banknote**：本人头像上过正式流通纸币（葛饰北斋的浪上过日元但非头像，不算）；
- **posthumous**：身后名显著大于生前（梵高、卡夫卡、曹雪芹、杜甫、徐霞客）；
- **emigrated**：连续或累计约五年以上定居国外，或改国籍。

### 排期机制

固定种子（1129）洗牌人物数组得全球一致的排期表 `PERM`，
第 N 期人物 = `PERM[(N-1) mod 111]`。第 1 期 = 2026-07-04（`EPOCH0`）。
期号由用户本地日期算出（QUALITY_BRIEF 的 Wordle 同款公式），全球同一天同题。
新增人物**只允许 push 到数组尾部**：洗牌序列对已发行期号保持稳定（见运营节奏）。

### 防剧透的边界

纯客户端游戏，答案在源码里可查——这与 Wordle 相同，不做对抗。
分享卡零剧透是产品红线；源码剧透是自选行为，不影响传播链路。

## 四、数值设计

- **计数**：每问一题 +1，每猜错一次 +1，猜中的那一下也计入（轨迹里就是 🎯）；
  "查无此人"的输入不计次。
- **问数分档**（46 问全问完也能锁定任何人，理论最优约 log₂111 ≈ 7 问）：

| 问数 | 称号 | 定位 |
|------|------|------|
| ≤5 | 神探 | 运气+直觉封神，值得截图 |
| 6–8 | 老练 | 熟练玩家的正常水位 |
| 9–12 | 稳健 | 按部就班二分收网 |
| 13–17 | 执着 | 绕了远路但没放弃 |
| ≥18 | 通读全卷 | 把辞典翻了个遍 |

- **放弃**：问满 8 题后出现"翻到答案页"入口；放弃计为未破解，连胜清零——
  给卡死的玩家台阶，也保护连胜的含金量。
- **连胜**：仅当日正赛计；昨天赢+今天赢 = +1，中断归 1，放弃归 0。
  连胜、最佳问数（历史最少）、总破解期数存 localStorage（`dailyperson.v1`，
  带版本号，解析失败回退默认值）。
- **练习**：档案页可玩已发行的往期（最多回溯 90 期），成绩单独记录，不碰连胜与纪录。

## 五、逐屏旅程

1. **报头**：三色报头（人字纹章 + 品名 + 期号/日期），双细线镇住版面；
2. **谜题页首屏**：状态栏（已问 N 题/连胜/玩法/档案）→ 猜名框 → 五枚索引签 →
   问题索引条。零说明书，问题本身就是教程；"玩法"折叠面板给要读规则的人；
3. **问答反馈**：点击问题 <100ms 内三件事同时发生——中央落章（是=靛蓝/否=朱砂，
   180ms 落定）、索引条原位盖上小章、问询记录追加一行；aria-live 同步播报；
4. **猜名**：输入即出候选（人名+命中的别名），点候选直接提交；猜错朱砂"否"章 +
   "不是 XX。已计一次。"；猜中盖"猜中"章，760ms 后翻页；
5. **辞条页**：像一页辞典——首字纹章（人物首字，朱砂印框）、姓名、生卒年
  （en-dash，公元前记"前 xxx"）、国别·领域、双栏小传（首字下沉）、墓志铭引条；
   之下是战绩（N 问破解 · 称号 + 轨迹）、复制/存图、连胜统计、倒计时、档案入口、
   自推广位（AdSense 挂点）；
6. **档案页**：期号列表（日期 + 练习状态），点击进练习局（虚线横幅提示不计连胜）；
7. **跨午夜**：页面开着过零点，30s 内底部弹墨条"新的一期已经开始"+ 刷新按钮。

## 六、动效与视觉规格

- **三色**：米白纸底 `#f5efe3` / 深墨 `#221b12` / 朱砂 `#b23a2b`（是章用靛蓝 `#2c4a72`，
  属于功能色不算点缀色扩容）；纸面有 32px 周期的极淡横纹；
- **字**：全衬线栈 `Georgia, Times New Roman, Songti SC, SimSun, serif`；
  字阶 1.25 模数（12.8/16/20/25/31.25px）；间距 4/8px 体系；
- **落章**：`stamp-in` 700ms 总时长，前 26%（约 180ms）从 1.9 倍缩放砸到 1 倍并回正 6°，
  停留后淡出；缓动统一 `cubic-bezier(0.16,1,0.3,1)`；只动 transform/opacity；
  `prefers-reduced-motion` 下直接呈现无动画；
- **索引签**：分类 tab 像辞典侧签，选中签墨底反白并上移 2px；问题条左侧"问"字朱砂小标，
  答完变旋转 -4° 的小章；
- **触控**：所有可点目标 ≥44px；375px 无横向滚动；焦点环 2px 朱砂。

## 七、分享卡规格

**文本版**（一键复制）：

```
每日一人 #37
🟦🟥🟦🟥🟦🟦🎯

```

🟦=答"是"，🟥=答"否"**或猜错**，🎯=猜中，按实际顺序；放弃则无 🎯，第三行为
"未破解，明天再战"。**任何情况下不出现人名。**

轨迹格（蓝方=是，红方=否，红圈=猜中，每行 8 格）+ "N 问破解 · 称号" + 图例 + 底部域名。
全 canvas 手绘，无外部图片字体。

## 十、已知边界

- 属性口径再严也替代不了常识分歧（如"庄子算不算文学家"）——口径写死在本文件与
  `questions.js` 头注释，客服话术统一引用口径；
- 在世人物的 `died/alive` 需人工维护：每季度校对一次库存在世名单；
- `l3`（世界大战）对 2001 年后出生者恒为否，属可接受的低区分问题；
- 编辑距离容错对两字中文名不生效（李白打成"李百"不命中），是防误报的刻意取舍，
  由别名（李太白/Li Bai）兜底。
