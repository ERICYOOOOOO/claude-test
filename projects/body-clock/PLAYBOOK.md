# 体内时钟 Body Clock — 策划案 / PLAYBOOK

掐秒游戏。屏幕给一个目标时长（如 7.00 秒），按住，心里数，松开——看你的体内时钟差了多少毫秒。每日一题，全球同题，三次机会。

---

## 一、为什么这个玩法在微信/抖音会火

**1. 一局 15 秒，验证成本为零。**
规则一句话说完（"按住数到 7 秒再松开"），第一次交互本身就是教学。转发到群里的人不需要解释玩法，收到的人不需要下载、不需要注册，点开 15 秒后就有一个自己的成绩。裂变链条上没有任何摩擦点。

**2. 毫秒误差是天然的炫耀货币。**
"误差 0.038 秒"是一个不需要上下文就能被理解、且可以被立刻反驳的数字——"不可能，我来"。这和 Wordle 的绿黄格同构：**成绩本身构成挑战书**。称号体系（原子钟→日晷）把连续数值折成六个可传播的身份标签，"我是石英表你是日晷"比"我 38ms 你 620ms"更有群聊张力。

**3. 全球同题制造公共话题。**
每日种子意味着今天所有人掐的都是同一个 7.42 秒。群里的比较是同题对比而非各玩各的，"今天这个 11.53 秒太阴间了"本身就是话题。错过一天就永远错过第 N 期，配合连胜机制形成每日回访钩子。

**4. 激励视频挂点顺滑，不破坏体验。**
两个挂点都在玩家主动想要的时刻出现：三次打完不甘心时（"再来一次机会"），和想追求带 ★ 的高含金量成绩时（"解锁干扰模式"）。都是拉动型（player-pulled）而非打断型广告，eCPM 与完播率天然高。

**5. 天然适配短视频。**
按住时屏幕安静得像一块表，松开瞬间数字砸出来——一个悬念、一个揭晓，正好是 3 秒的短视频钩子结构。见 MARKETING.md 的拍摄脚本。

## 二、核心循环

```
看目标（7.00s）→ 按住表盘（无任何计时显示，只有呼吸脉动）
→ 心里数 → 松开 → 秒针回摆指向误差，毫秒数字入场 → 称号
→（还有机会？再来 ×3 取最好）→ 结算：称号 + 迷你格 + 分享
→ 明天换题
```

单局 5–15 秒。每日总时长约 1 分钟——刻意保持稀缺，练习模式承接超量需求。

## 三、数值表

### 3.1 每日目标

| 项 | 值 | 说明 |
|---|---|---|
| 目标区间 | 3.00–12.00 秒 | 两位小数（厘秒粒度） |
| 生成 | mulberry32(dayIndex ⊕ 0x5f356495)，丢弃前两个输出 | 均匀分布，全球同题 |
| 换题时刻 | 用户本地零点 | 与 Wordle 同口径 |
| 期号 | 2026-06-17 为第 1 期 | 分享卡带期号 |

短目标（3–5s）考验反应型直觉，长目标（9–12s）考验默数稳定性——区间刻意拉宽让"今天题目难"成为话题变量。

### 3.2 称号档（按当日最好误差）

| 误差 | 称号 | 分享符号 | 设计定位 |
|---|---|---|---|
| ≤ 10ms | 原子钟 | ⚛️ | 传说档。基本靠运气+状态，出现即截图 |
| ≤ 30ms | 铯钟 | 🛰️ | 极稀有，值得炫耀 |
| ≤ 80ms | 石英表 | ⌚ | 高手线。练习后可稳定触达 |
| ≤ 200ms | 机械表 | ⚙️ | 及格线 = 守时线，多数认真玩家的日常 |
| ≤ 500ms | 沙漏 | ⏳ | 有点丢人但不至于挂零 |
| > 500ms | 日晷 | 🌞 | 群聊里的快乐源泉 |

档位设计原则：底部两档（沙漏/日晷）要足够容易踩中，让"翻车"也可分享；顶部两档要稀有到值得开干扰模式去"验金"。数值可在 `shared/core.js` 的 `TIERS` 一处调整，三端同步生效。

### 3.3 机会与连胜

| 项 | 值 |
|---|---|
| 每日正式机会 | 3 次，取最好 |
| 误触保护 | 按住 < 200ms 不计入 |
| 广告加时 | 看激励视频 +1 次，每天限 1 次 |
| 守时判定 | 当日最好误差 ≤ 200ms |
| 连胜 | 连续守时天数；漏一天或超标即断 |
| 连胜计算 | 逐日回溯（非增量计数），存档修复/广告改成绩后自洽 |

### 3.4 干扰模式 ★

| 项 | 值 |
|---|---|
| 默认 | 关闭；看一条激励视频永久解锁 |
| 效果 1 | 按住期间播放不规则轻响：间隔 380–1400ms 随机，音高 420–1720Hz 随机 |
| 效果 2 | 表盘缓慢变色（两层色晕以 7s/9s 异相位漂移），干扰视觉锚点 |
| 成绩标记 | 开启状态下打出的成绩带 ★（尝试格、称号、分享文本、PNG 全链路） |

**防数秒对策（设计意图写透）**：本作无法也不打算阻止"心里数 1001、1002"——那本来就是玩法的一部分。干扰模式针对的是数秒的两个依赖：**节奏感**（不规则轻响的间隔刻意避开 0.5s/1s 整数倍，让默数节拍被带偏）和**视觉锚点**（缓慢变色让玩家无法用画面稳定性做参照）。★ 成绩因此成为"裸奏"的含金量证明，社区自然形成"★ 才算真本事"的鄙视链——这是把反作弊做成了炫耀升级，而不是惩罚。

### 3.5 变现挂点

| 挂点 | 时机 | 形式 |
|---|---|---|
| 再来一次机会 | 结算屏，3 次用完 | 激励视频（H5 占位 → wx/tt.createRewardedVideoAd） |
| 解锁干扰模式 ★ | 结算屏 / 设置开关 | 激励视频，一次性解锁 |
| 结果页广告位 | 结算屏下方 | 默认极简自推广位，AdSense/流量主激活见注释 |

## 四、逐屏旅程

### S0 首屏（即玩）
灰白表盘卧在精钢深灰底上。目标数字 47px 加粗居中，表盘中心一行"按住"。无引导浮层、无弹窗——第一次按住+松开就是全部教学。已有成绩时头部出现"守时连胜 n 天"。

### S1 按住（悬念）
- 秒针 200ms 淡出（**按住期间不显示任何计时**）。
- 朱红脉动环 2.8s 周期呼吸（scale 0.97→1.03，opacity 0.16→0.45）。
- 中心字变"……"，字距拉宽。按下瞬间轻震 15ms + 2100Hz/18ms 轻响。
- 干扰模式开启时：色晕漂移 + 不规则轻响启动。

### S2 揭晓（高潮）
- 松开瞬间：轻震 30ms + 1300Hz 轻响。
- 秒针以 760ms 弹簧曲线（cubic-bezier(0.22,1.5,0.36,1)，带过冲）回摆指向误差角：0ms 指正上，提前偏左、拖后偏右，±500ms 封顶 ±90°。
- 误差数字"表针回摆"式入场：rotate(-8°)→+2.5°→0°，640ms 同弹簧曲线。
- 依次出现：目标 / 你按了 / 误差（大字）/ 方向（"数快了 · 提前 50 毫秒"）/ 称号（延迟 220ms 升入）。
- 尝试格即时更新（Ⅰ Ⅱ Ⅲ，下划线按绿/黄/红着色）。

### S3 结算（分享）
最好成绩大字 + 称号 + 三格迷你格 + 连胜状态。两个分享按钮（复制战报 / 保存图片）、两个激励视频挂点、下一期倒计时、自推广位。表盘中心字变"已锁定"，再按只弹提示。

### S4 练习模式
不限次、不计入、随机目标。尝试格隐藏，提示词换为"练习 · 不限次 · 不计入正式成绩"。承接"还想玩"的需求，保护每日模式的稀缺性。

## 五、动效与视觉规格

### 5.1 色板（精密仪器/腕表工艺）

| 名 | 值 | 用途 |
|---|---|---|
| 精钢深灰 | `#2b2d31` | 页面底、分享卡底 |
| 表盘灰白 | `#e9e7e2` | 表盘、卡片 |
| 朱红 | `#c8372d` | 秒针、★、开关、焦点环——全站唯一强调色 |
| 墨 | `#2b2d31` / `#5b5e64` | 卡上正文/次要 |
| 浅灰 | `#d8d9db` / `#94969c` | 深底正文/次要 |
| 绿/黄/红格 | `#3f7350` / `#a8811f` / `#b23a2e` | ≤80 / ≤200 / >200ms |

禁用项按全局质量基准执行：无渐变底、无玻璃拟态、无圆角阴影全家桶。卡片圆角统一 6px、按钮 3px，边框 1px。

### 5.2 字阶与排版
- 1.25 模数：12 / 15 / 19 / 24 / 30 / 37 / 47 / 74(clamp)。
- 全部数字 `font-variant-numeric: tabular-nums`——误差数字逐帧对齐，像仪表读数。
- 拉丁小标（BODY CLOCK / TARGET / DEVIATION）字距 0.22em，模拟表盘刻字。
- 系统字体栈，零外部字体。

### 5.3 缓动与时长表

| 动效 | 时长 | 曲线 |
|---|---|---|
| 秒针回摆 | 760ms | cubic-bezier(0.22,1.5,0.36,1) 过冲弹簧 |
| 误差数字入场 | 640ms | 同上 |
| 称号升入 | 420ms（延迟 220ms） | cubic-bezier(0.16,1,0.3,1) |
| 秒针隐/现 | 200ms | 同上 |
| 脉动环 | 2.8s 循环 | ease-in-out |
| 按钮/开关 | 180–200ms | cubic-bezier(0.16,1,0.3,1) |

只动 transform/opacity；`prefers-reduced-motion` 下全部降至 0.01ms（秒针直接跳到位）。

### 5.4 触觉与声音
- 按下 15ms / 松开 30ms 轻震（`navigator.vibrate`，无则静默；小游戏走 `wx/tt.vibrateShort`）。
- 按下 2100Hz、松开 1300Hz 的 20ms 级正弦轻响，可在设置关闭。AudioContext 首次手势后惰性创建。

## 六、分享卡规格

### 6.1 文本版（复制到剪贴板）
```
体内时钟 #23 · 目标 7.00s · 误差 0.038s ⌚ 石英表
🟩🟨🟥
守时连胜 5 天 · bodyclock.fun
```
- 迷你格逐次着色：🟩 ≤80ms、🟨 ≤200ms、🟥 >200ms；有广告加时则第 4 格照排。
- ★ 直接缀在称号后（`石英表★`）。连胜 >1 天才显示尾行前半。
- **零剧透**：不含目标以外的任何当日信息，收到的人仍要自己掐。

## 七、技术架构

```
projects/body-clock/
  index.html / style.css / app.js   H5 本体（file:// 可开，零依赖，总重 ~56KB）
  shared/core.js                    纯函数核心：种子/判定/称号/连胜/分享文本/角度
  wechat-minigame/
    game.js                         Canvas 核心循环（按住/松开/结算/称号）
    adapter.js                      wx./tt. 全部集中于此（震动/广告/分享/存储）
    shared/core.js                  core 的逐字节副本（test 校验一致性）
    game.json / project.config.json
  test/core.mjs                     node 直测 core（40 项）
  test/smoke.mjs                    Playwright 冒烟（48 项）
```

- **core 三端共用**：H5 `<script>` 挂 `window.BodyClockCore`，小游戏与 Node `require`（UMD）。改判定只改一处，`cp shared/core.js wechat-minigame/shared/core.js` 后测试守门。
- **计时**：H5 用 `performance.now()` 差值；判定精度与显示精度均为 1ms。
- **存档** `localStorage['bodyclock.v1']`：`{v, days:{dayIndex:{attempts,extra,done,bestErrMs}}, settings}`。任何垃圾输入经 `normalizeState` 回退；仅保留最近 400 天。
- **时钟注入**：`window.__BC_NOW__` + `__bc.setNow()`，测试跨天换题；30s 轮询 + visibilitychange 处理真实跨午夜。

### 后续路线图
1. **好友 PK 榜**（最优先）：微信群排行榜（wx.getGroupCloudStorage 拉群内成绩），"本群今日最准"——分享动机从炫耀升级为占坑。

3. **双向模式**：反向掐秒（给时长后倒数）、盲掐（不给目标，松开后才揭晓目标是几秒）作节日限定题型。
4. **成就墙**：原子钟次数、最长连胜、总掐秒次数——全部本地统计，零后端不变。
